# Power Supply - DC to AC Inverter

## What is a DC to AC Inverter?

A DC to AC inverter (commonly called just "inverter") is an electronic device that converts direct current (DC) from a battery or solar panel into alternating current (AC) similar to what comes from a wall outlet. This allows battery-powered systems to run standard AC appliances, lights, tools, and electronics.

Inverters are essential for off-grid living, RVs, boats, solar power systems, backup power, and emergency preparedness. They enable us to use the vast ecosystem of AC devices with DC power sources like batteries and solar panels.

## Basic Principles

### What an Inverter Does

An inverter takes low-voltage DC and produces high-voltage AC.

```
INVERTER FUNCTION

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   DC Input              INVERTER              AC Output     │
    │   (Battery)                │                 (120V/230V)    │
    │        │                   │                       │        │
    │        ▼                   ▼                       ▼        │
    │   ┌─────┐               ┌─────┐                ┌─────┐      │
    │   │ 12V │               │     │                │120V │      │
    │   │ DC  │──────────────►│     ├───────────────►│ AC  │      │
    │   │     │               │     │                │     │      │
    │   └─────┘               └─────┘                └─────┘      │
    │                                                             │
    │   Low voltage           Power conversion      High voltage  │
    │   High current          electronics           Low current   │
    │   (e.g., 100A)                               (e.g., 10A)    │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘


    POWER BALANCE:

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Input Power = Output Power ÷ Efficiency                   │
    │                                                             │
    │   Example: 1000W AC output, 90% efficient inverter          │
    │                                                             │
    │   Input power = 1000W ÷ 0.90 = 1111W                        │
    │                                                             │
    │   For 12V system:   I_in = 1111W ÷ 12V = 92.6A              │
    │   For 24V system:   I_in = 1111W ÷ 24V = 46.3A              │
    │   For 48V system:   I_in = 1111W ÷ 48V = 23.1A              │
    │                                                             │
    │   Higher voltage = lower current = thinner wires!           │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### Basic Inverter Block Diagram

```
INVERTER BLOCK DIAGRAM

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   DC Input ──► DC-DC Boost ──► H-Bridge ──► Filter ──► AC  │
    │   (12/24/48V)    (to 170/325V)   (switches)   (LC)      Out │
    │                                                             │
    │                      │            │                         │
    │                      ▼            ▼                         │
    │                 High voltage    Square wave/    Sine wave   │
    │                 DC bus          PWM control     output      │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘


    STAGES EXPLAINED:

    Stage 1: DC-DC Boost Converter
    ├── Increases low battery voltage (12V/24V/48V) to high DC voltage
    ├── For 120V AC: need 170V DC bus (peak voltage)
    ├── For 230V AC: need 325V DC bus (peak voltage)
    └── Uses high-frequency transformer (small, light)

    Stage 2: H-Bridge (Inversion Stage)
    ├── Converts high voltage DC to AC
    ├── Uses MOSFETs or IGBTs as fast switches
    ├── Creates modified sine wave or PWM waveform
    └── Pulse Width Modulation (PWM) shapes sine wave

    Stage 3: Output Filter
    ├── LC filter (inductor + capacitor) smooths waveform
    ├── Removes high-frequency switching noise
    └── Produces clean sine wave (pure sine inverters)
```

## Types of Inverters

### Modified Sine Wave Inverter

Simpler, cheaper, but produces a "blocky" waveform.

```
MODIFIED SINE WAVE

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Voltage                                                  │
    │        │                                                  │
    │   +V ┼───┐    ┌───┐    ┌───┐                              │
    │        │    │    │    │    │                              │
    │        │    │    │    │    │                              │
    │        │    │    │    │    │                              │
    │       0┼───┴────┴────┴────┴───────────────────────────   │
    │        │                                                │
    │        │                                                │
    │   -V ┼───┐    ┌───┐    ┌───┐                              │
    │        │    │    │    │    │                              │
    │        │    │    │    │    │                              │
    │        └────┴────┴────┴────┘                              │
    │        │                                                 │
    │        └────────────────────────────────────────► Time   │
    │                                                             │
    │   Waveform is a stepped square wave (approximates sine)   │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘

    CHARACTERISTICS:
    ├── Stepped square wave approximation of sine wave
    ├── Less expensive than pure sine
    ├── More efficient than pure sine (typically 85-90%)
    ├── Higher total harmonic distortion (THD >30%)
    ├── Can cause buzzing in some devices (motors, audio)
    ├── May not work with some electronics (battery chargers, CPAP)
    ├── Universal motors (power tools) run but may run hot
    ├── Transformers may hum loudly
    └── Lower cost (typically 30-50% less than pure sine)


    COMPATIBLE DEVICES:
    ├── Resistive loads (heaters, incandescent lights, toasters)
    ├── Universal motors (vacuum cleaners, drills, saws)*
    ├── Some power supplies (computer PSUs - often fine)
    ├── Phone chargers (usually work)
    ├── LED lights (may flicker or hum)
    └── Basic electronics (often fine, but risk)

    *May run hotter than on grid power; check manufacturer

    INCOMPATIBLE / PROBLEMATIC DEVICES:
    ├── Laser printers (may not sync)
    ├── Medical devices (CPAP, oxygen concentrators - check!)
    ├── Audio equipment (may buzz or hum)
    ├── Digital clocks (may run fast/slow)
    ├── Some battery chargers (may not work correctly)
    ├── Microwave ovens (reduced power, odd sounds)
    └── Fluorescent lights (may flicker or not start)
```

### Grid-Tie Inverter

Synchronizes with utility grid for solar systems.

```
GRID-TIE INVERTER

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Solar Panels (DC) ──► Grid-Tie Inverter ──► Utility Grid │
    │         │                      │                    │       │
    │         ▼                      ▼                    ▼       │
    │    200-400V DC             Sync with grid        120/230V   │
    │                           (60/50 Hz)              AC        │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘

    SPECIAL FEATURES:
    ├── Synchronizes frequency and phase with utility grid
    ├── Shuts down if grid power fails (anti-islanding)
    ├── Maximum Power Point Tracking (MPPT) for solar
    ├── Bidirectional power flow
    ├── High efficiency (95-98%)
    ├── Requires grid connection (doesn't work off-grid)
    └── Must meet utility interconnection requirements

    USE: Grid-tied solar systems (export power to utility)
```

### Off-Grid vs Grid-Tie vs Hybrid

```
INVERTER TYPE COMPARISON

    Type                Use Case              Battery?    Grid?
    ──────────────────────────────────────────────────────────────
    Off-Grid Inverter   Remote cabin, RV      Yes         No
    Grid-Tie Inverter   Home solar export     No          Yes
    Hybrid Inverter     Home backup + solar   Yes         Yes


    OFF-GRID INVERTER:
    ├── Takes power from battery bank
    ├── Can't feed power back to grid
    ├── Shuts off when batteries low
    ├── Often includes battery charger (AC to DC)
    └── Standalone operation only


    GRID-TIE INVERTER:
    ├── Takes power from solar panels (DC)
    ├── Feeds power to utility grid
    ├── Shuts down during grid outage (safety)
    ├── No battery required
    └── Only works when grid is present


    HYBRID INVERTER:
    ├── Works off-grid (battery power)
    ├── Works grid-tied (export solar)
    ├── Can charge batteries from grid or solar
    ├── Seamless switch between modes
    ├── Backup power during grid outage
    └── Best of both worlds (most expensive)
```

```
    1000W load, 90% efficient inverter:
    Input power = 1000W ÷ 0.90 = 1111W

    Larger inverters need cooling fans or heatsinks.
```

Inverters consume power even with nothing plugged in.

```

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Power wasted when inverter is ON but nothing plugged in  │
    │                                                             │
    │   Typical idle draw:                                       │
    │   ├── Small inverter (150-300W):    5-15W                  │
    │   ├── Medium inverter (500-1000W):  15-30W                 │
    │   ├── Large inverter (1500-3000W):  30-60W                 │
    │   ├── Very large (>3000W):          50-100W+               │
    │                                                             │
    │   High-end inverters have "search" or "eco" mode           │
    │   (pulses every few seconds, draws 1-5W)                   │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘


    BATTERY DRAIN EXAMPLE (12V, 100Ah battery):

    Idle draw 20W:
    Current = 20W ÷ 12V = 1.67A
    Battery life = 100Ah ÷ 1.67A = 60 hours (2.5 days!)

    LESSON: Turn inverter OFF when not in use!
    Otherwise it will drain your batteries.
```

### Battery Sizing for Inverters

```
BATTERY BANK SIZING

    FORMULA:
    Battery Capacity (Ah) = (Load (W) × Runtime (h)) ÷ (Battery V × DoD × Efficiency)


    EXAMPLE: Run 500W load for 4 hours using 12V system

    Energy needed = 500W × 4h = 2000Wh

    Battery capacity (with 80% DoD, 90% inverter efficiency):
    = 2000Wh ÷ (12V × 0.80 × 0.90)
    = 2000Wh ÷ (12V × 0.72)
    = 2000Wh ÷ 8.64V
    = 231Ah

    For lead-acid (50% DoD recommended):
    = 2000Wh ÷ (12V × 0.50 × 0.90)
    = 2000Wh ÷ (12V × 0.45)
    = 2000Wh ÷ 5.4V
    = 370Ah


    QUICK REFERENCE (12V system, 1 hour runtime):

    Load (W)    Battery Ah (Lead-acid 50%)    Battery Ah (LiFePO₄ 80%)
    ──────────────────────────────────────────────────────────────
    150W        30Ah                         20Ah
    300W        60Ah                         40Ah
    500W        100Ah                        65Ah
    1000W       200Ah                        130Ah
    1500W       300Ah                        195Ah
    2000W       400Ah                        260Ah

    Note: Multiply by runtime hours for longer operation.
```

## Installation and Wiring

### DC Input Wiring

Proper DC wiring is critical for safety and performance.

```
DC WIRING REQUIREMENTS

    CABLE SIZING (for 3% voltage drop, copper, 12V system):

    Inverter Size    Max Current    Cable Length (round trip)
                     (at 10.5V)     10ft    20ft    30ft
    ──────────────────────────────────────────────────────────────
    300W            30A            10 AWG   8 AWG   6 AWG
    500W            48A            8 AWG    6 AWG   4 AWG
    1000W           95A            4 AWG    2 AWG   1 AWG
    1500W           143A           2 AWG    1/0 AWG  2/0 AWG
    2000W           190A           1 AWG    2/0 AWG  3/0 AWG
    3000W           285A           2/0 AWG  3/0 AWG  4/0 AWG


    CRITICAL RULES:

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   ☐ Use proper gauge wire (undersized wire = fire!)        │
    │   ☐ Keep DC wires as short as possible                     │
    │   ☐ Use fused connection at battery (within 18 inches)     │
    │   ☐ Use Class T or ANL fuse (not automotive glass fuse)    │
    │   ☐ Crimp, don't solder, large terminals (cold joints)    │
    │   ☐ Use proper lugs and heat shrink                       │
    │   ☐ Torque connections to specification                    │
    │   ☐ Check connections for heat after installation         │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘


    FUSE SIZING:

    Fuse rating = Inverter max input current × 1.25 (125%)

    Example: 1000W inverter, 12V system
    Max current = 1000W ÷ 10.5V (low battery) = 95A
    Fuse = 95A × 1.25 = 119A → use 125A or 150A fuse
```

```
    │                                                             │
    │   Inverter with transfer switch: Bond in main panel        │

    │                                                             │
    │   Multiple bonds = ground loops = shock hazard!           │
```

## Troubleshooting

### Problem 1: Inverter Won't Turn On

```
SYMPTOMS:
├── No lights, no display, no output
├── Fan doesn't spin
├── Completely dead

CAUSES:
├── Dead battery (voltage below low-voltage cutoff)
├── Blown fuse (overload or short)
├── Loose battery connection
├── Reverse polarity (inverter destroyed)
├── Defective on/off switch
├── Internal failure

DIAGNOSIS:
├── Measure battery voltage (should be >11V for 12V system)
├── Check fuse continuity (multimeter)
├── Check battery connections (tight, clean)
├── Test voltage at inverter terminals
├── Check polarity (red to +, black to -)

SOLUTIONS:
├── Charge or replace battery
├── Replace fuse (correct rating)
├── Clean and tighten connections
├── If reverse polarity: Inverter likely destroyed (replace)
├── Check switch with multimeter (continuity)
├── For internal failure: replace inverter (not cost-effective to repair)
```

### Problem 2: Inverter Shuts Off Under Load

```
SYMPTOMS:
├── Runs for a few minutes, then shuts off
├── Shuts off immediately when heavy load connected
├── Beeps error code before shutoff

CAUSES:
├── Battery voltage drops below low-voltage cutoff
├── Battery too small (high internal resistance)
├── Undersized DC cables (voltage drop)
├── Loose connection (high resistance)
├── Overload (load exceeds inverter rating)
├── Overheating (poor ventilation)

DIAGNOSIS:
├── Measure battery voltage under load (while inverter running)
├── Voltage should stay above 11V (12V system)
├── Check voltage at inverter terminals (compare to battery)
├── Voltage drop >0.5V indicates undersized cables or loose connections
├── Check inverter temperature (should be <50°C)
├── Measure load current (clamp meter)

SOLUTIONS:
├── Larger battery bank (reduce voltage drop)
├── Thicker DC cables (reduce voltage drop)
├── Clean/tighten all connections
├── Reduce load (add second inverter for heavy loads)
├── Improve ventilation (add fan)
├── Check inverter rating matches load (add 20-30% margin)
```

### Problem 3: No AC Output (but inverter turns on)

```
SYMPTOMS:
├── Inverter lights on, fan running
├── But no AC voltage at outlet
├── Error light or code

CAUSES:
├── Output overload (tripped)
├── Short circuit in AC wiring
├── Defective output MOSFETs
├── Internal fuse blown (some inverters have internal fuses)
├── Over-temperature shutdown (not reset yet)

DIAGNOSIS:
├── Turn inverter off, disconnect all AC loads
├── Turn back on, measure AC output (should be 120V/230V)
├── If output present: load problem (faulty device)
├── If still no output: inverter internal problem
├── Check AC wiring for shorts

SOLUTIONS:
├── Reset inverter (turn off, wait 30 seconds, turn on)
├── Check AC devices individually (bad appliance)
├── For internal failure: replace inverter
├── For temperature: let cool, improve ventilation
```

### Problem 4: Poor Waveform / Dirty Power

```
SYMPTOMS:
├── Lights flicker
├── Motors run hot or noisy
├── Electronics malfunction
├── Audio equipment hums
├── Digital clocks run fast/slow

CAUSES:
├── Modified sine wave inverter (normal behavior)
├── Overloaded inverter (waveform distorts)
├── Low battery voltage (poor waveform)
├── Defective inverter (failing components)
├── Inverter too small for inductive loads

DIAGNOSIS:
├── Check if pure sine or modified sine
├── If modified sine: normal for some devices (replace with pure sine)
├── Measure output voltage (should be 120V/230V ±5%)
├── Check voltage under load (should not drop significantly)
├── Check with oscilloscope (if available – should be clean sine)

SOLUTIONS:
├── Replace modified sine with pure sine inverter
├── Reduce load (inverter overload distorts waveform)
├── Maintain battery voltage (larger bank, better charging)
├── For sensitive electronics: use pure sine inverter
├── Add line conditioner or UPS for sensitive loads
```

## Summary

1. **Inverter** converts DC (battery/solar) to AC (wall outlet power)

2. **Power balance:** Input power = Output power ÷ Efficiency

3. **Higher DC voltage** = lower current = thinner wires = less loss

4. **Modified sine wave:** cheaper, blocky waveform, THD>30%, some devices don't work

5. **Pure sine wave:** cleaner, works with everything, THD<3-5%, more expensive

6. **Modified sine problems:** motors run hot, audio buzzes, digital clocks inaccurate, medical devices may fail

7. **Continuous rating** = power inverter can supply continuously

8. **Surge rating** = peak power for starting motors (2-3× continuous)

9. **Size inverter** for running load + 50% margin + largest surge requirement

10. **Idle draw** wastes battery (5-60W) – turn inverter OFF when not in use

11. **Voltage drop** kills performance – use proper DC wire gauge

12. **Fuse at battery** within 18 inches – Class T or ANL (not glass fuse)

13. **12V system** suitable for ≤2000W, 24V for ≤4000W, 48V for ≥4000W

14. **Wire sizing:** 1000W @12V needs 4 AWG (10ft), 1000W @48V needs 8 AWG

15. **Battery bank sizing:** Ah = (Watts × Hours) ÷ (Voltage × DoD × Efficiency)

16. **Lead-acid** use 50% DoD, **LiFePO₄** use 80% DoD

17. **Safety:** 120V/230V AC can kill – treat like wall outlet

18. **High current DC** can cause arc flash – disconnect battery before working

19. **Never reverse polarity** – destroys inverter (often instantly)

20. **Ventilation required** – inverters generate heat, need airflow
