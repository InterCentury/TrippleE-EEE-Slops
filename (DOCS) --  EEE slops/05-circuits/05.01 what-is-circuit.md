# 05.01 - What is a Circuit?

## Core Definition of an Electrical Circuit

An electrical circuit is a closed, continuous loop of conductive material that allows electric charge to flow from a point of high potential energy to a point of low potential energy. The fundamental driving force behind this movement is the electromagnetic force, which directs free electrons through a path of components to perform useful work (such as generating heat, producing light, or computing logic states).

Every functional circuit requires three basic elements to exist:

1. **An Energy Source:** A device (like a battery, generator, or solar cell) that creates a potential difference across its terminals.
2. **A Conductive Path:** A material (typically copper or aluminum wiring) that provides an uninterrupted path for electron migration.
3. **A Load:** A component (such as a resistor, motor, or lamp) that consumes electrical energy and converts it into another form of energy.

If any of these three core elements are missing or disconnected, the circuit ceases to function.

## Fundamental Circuit Topologies

The structural arrangement of components within a loop dictates how voltage drops and currents distribute across the network. The two primary foundational layouts are series and parallel configurations.

### 1. Series Circuit Architecture

In a series configuration, components are connected end-to-end along a single path. This means the same current must flow through every component in succession.

```text
  Direct Current (DC) Voltage Source Input Terminal
  ┌───────────────────────────────┐
  │ (+) Positive Terminal Rail    │
  └──────────────┬────────────────┘
                 │
                 ▼
         ┌───────────────┐
         │ Resistor R1   │ (First Load Element)
         └───────┬───────┘
                 │
                 ▼
         ┌───────────────┐
         │ Resistor R2   │ (Second Load Element)
         └───────┬───────┘
                 │
                 ▼
  ┌──────────────┴────────────────┐
  │ (-) Negative Terminal Return  │
  └───────────────────────────────┘

```

* **Current Characteristics:** The current ($I$) remains identical at every point in the loop:

$$I_{\text{total}} = I_1 = I_2 = I_3 = \dots$$


* **Voltage Behavior:** The total voltage supplied by the source is distributed across the components as individual voltage drops:

$$V_{\text{total}} = V_1 + V_2 + V_3 + \dots$$


* **Critical Vulnerability:** If a single component fails or opens in a series configuration, the entire path breaks, and all current stops flowing instantly.

### 2. Parallel Circuit Architecture

In a parallel configuration, components are connected across the same two common nodes, creating multiple independent branches for current to flow through.

```text
  Source (+) ────┬───────────────────────┬───────────────────────┐
                 │                       │                       │
                 ▼                       ▼                       ▼
         ┌───────────────┐       ┌───────────────┐       ┌───────────────┐
         │ Branch Load 1 │       │ Branch Load 2 │       │ Branch Load 3 │
         │ (Resistor R1) │       │ (Resistor R2) │       │ (Resistor R3) │
         └───────┬───────┘       └───────┬───────┘       └───────┬───────┘
                 │                       │                       │
  Source (-) ────┴───────────────────────┴───────────────────────┘

```

* **Voltage Characteristics:** The voltage ($V$) across each parallel branch is identical to the source voltage:

$$V_{\text{total}} = V_1 = V_2 = V_3 = \dots$$


* **Current Behavior:** The total current leaving the source splits among the available branches based on their individual resistance values:

$$I_{\text{total}} = I_1 + I_2 + I_3 + \dots$$


* **Operational Resilience:** If one branch opens or fails, the remaining branches continue to operate normally because their independent connections to the voltage source remain intact.

## Primary Circuit States

Electrical circuits exist in one of three distinct operating conditions, determined by the integrity of the conductive pathway.

### 1. Closed Circuit

The conductive pathway is entirely unbroken, creating a complete loop. Current flows normally from the source, through the load, and back to the source return terminal.

### 2. Open Circuit

The conductive loop is broken or interrupted (e.g., by an open switch, snapped wire, or blown fuse). The air gap introduces a near-infinite resistance ($R \to \infty$), which stops all current flow ($I = 0\text{A}$), disabling the load.

### 3. Short Circuit

An accidental, low-resistance path bypasses the intended load. This shifts the circuit's total resistance toward zero ($R \to 0\Omega$), causing a massive spike in current flow according to Ohm's Law ($I = \frac{V}{R}$). This uncontrolled current draw can rapidly overheat wires and cause component fires if protective components fail to clear the fault.

```text
  Phase (Line) ───[Breaker]───────┬──────────────┐
                                  │              │ ⚡ ACCIDENTAL ACCIDENTAL DIRECT BRIDGE
                                  │              ▼  (Bypasses load completely)
```

## Summary Summary Checklist

1. **Continuous Loop Requirement:** A circuit must form an uninterrupted, closed path for current to flow and perform work.
2. **Three Core Pillars:** Every circuit requires an energy source, a conductive pathway, and an electrical load to function.
3. **Series Uniformity:** In a series circuit, current remains uniform throughout the loop, while the total voltage is divided among the loads.
4. **Parallel Branching:** In a parallel network, voltage remains constant across all branches, while the total current divides among them.
5. **Series Failure Mode:** A single open-circuit failure in a series loop disrupts the entire path and shuts down all downstream loads.
6. **Parallel Independence:** Standard domestic and industrial electrical distribution systems use parallel wiring to ensure individual appliances can operate independently.
7. **Ohm's Law Foundation:** Voltage, current, and resistance are linked linearly, dictating how a circuit responds to varying load conditions.
8. **Kirchhoff's Current Rule:** Current cannot collect at an intersection; every electron entering a node must exit it.
9. **Kirchhoff's Voltage Rule:** The electrical energy supplied by a source is fully accounted for by the voltage drops across the circuit's loads.
10. **Short Circuit Danger:** Short circuits eliminate load resistance, driving massive currents that can cause equipment damage or structural fires if not properly protected.
