# 07.01 - What is a Motor?

## What is an Electric Motor?

An electric motor is a machine that converts electrical energy into mechanical energy. It does this through the interaction of magnetic fields and current-carrying conductors, producing rotational force (torque) that can be used to perform useful work.

Electric motors are everywhere: they power fans, pumps, compressors, industrial machinery, electric vehicles, trains, robots, home appliances, and countless other devices. Over 45% of the world's electricity is consumed by electric motors, making them the single largest category of electrical load.

## Basic Principle

### How an Electric Motor Works

All electric motors operate on the same fundamental principle: a current-carrying wire in a magnetic field experiences a force.

```
    > FLEMING'S LEFT-HAND RULE (Orthogonal Vector Field Geometry)

                       [ THUMB ]
                    Force / Motion (F)
                          ▲
                          │
                          │   [ FIRST FINGER ]
                          │   Magnetic Field (B)
                          │   (North ──► South)
                          │         ┌─►
                          │       ┌─┘
                          │     ┌─┘
                          │   ┌─┘
                          └───┼─────────────────────► [ SECOND FINGER ]
                             ┌┘                          Conventional Current (I)
                           ┌─┘                           (Positive ──► Negative)
                          ┌┘
                         ▼
                [ Z-AXIS PROJECTION ]
              Vectors Mutually at 90°






    SIMPLE MOTOR CONCEPT:

    ┌─────────────────────────────────────────────────────────────────┐
    │                                                                 │
    │                        N ──────── S                             │
    │                      Magnet      Magnet                         │
    │                         │          │                            │
    │                         │          │                            │
    │                         │    ┌─────┴─────┐                      │
    │                         │    │           │                      │
    │                         │    │   Coil    │                      │
    │                         │    │  (wire)   │                      │
    │                         │    │           │                      │
    │                         │    └─────┬─────┘                      │
    │                         │          │                            │
    │                         │          │                            │
    │                         ▼          ▼                            │
    │                                                                 │
    │   When current flows through coil, forces act on the wire       │
    │   Forces create torque → Coil rotates                           │
    │   Commutator reverses current every half-turn                   │
    │   → Continuous rotation!                                        │
    │                                                                 │
    └─────────────────────────────────────────────────────────────────┘
```

### Lorentz Force Law

The mathematical foundation of motor operation.

```
LORENTZ FORCE LAW

    F = I × L × B

    WHERE:
    F = Force (Newtons)
    I = Current (Amperes)
    L = Length of conductor in magnetic field (meters)
    B = Magnetic field strength (Tesla)


    VISUAL EXAMPLE:

    ┌─────────────────────────────────────────────────────────────────┐
    │                                                                 │
    │              ┌───────────────────────────────────────┐          │
    │              │                                       │          │
    │              │     North Pole              South Pole│          │
    │              │    (N) ───────────────────── (S)      │          │
    │              │         │                    │        │          │
    │              │         │                    │        │          │
    │              │         │                    │        │          │
    │              │         │     I (current)    │        │          │
    │              │         │      ───────►      │        │          │
    │              │         │                    │        │          │
    │              │         │         │          │        │          │
    │              │         │         ▼          │        │          │
    │              │         │     Force (F)      │        │          │
    │              │         │                    │        │          │
    │              │         │                    │        │          │
    │              └───────────────────────────────────────┘          │
    │                                                                 │
    │   Force is perpendicular to BOTH current AND magnetic field     │
    │                                                                 │
    └─────────────────────────────────────────────────────────────────┘


    PRACTICAL VALUES:

    Typical motor parameters:
    ├── I = 10A (small motor)
    ├── L = 0.1m (coil length in field)
    ├── B = 0.5T (permanent magnet)
    └── F = 10 × 0.1 × 0.5 = 0.5 Newtons (approx 50g force)

    Multiple coils × multiple turns = much higher torque!
```

## Key Motor Parameters

### Torque

The twisting force produced by the motor.

```
TORQUE EXPLANATION

    ┌─────────────────────────────────────────────────────────────────┐
    │                                                                 │
    │   Torque (τ) = Force × Radius                                   │
    │                                                                 │
    │   τ = F × r                                                     │
    │                                                                 │
    │   WHERE:                                                        │
    │   τ = Torque (Newton-meters, N·m)                               │
    │   F = Force (Newtons)                                           │
    │   r = Radius (meters)                                           │
    │                                                                 │
    └─────────────────────────────────────────────────────────────────┘


    VISUAL EXAMPLE:

    ┌─────────────────────────────────────────────────────────────────┐
    │                                                                 │
    │                         ┌─────┐                                 │
    │                         │     │                                 │
    │                         │     │                                 │
    │                    r ───┤  o  ├─── F (Force)                    │
    │                         │     │                                 │
    │                         │     │                                 │
    │                         └─────┘                                 │
    │                           │                                     │
    │                           │                                     │
    │                         Shaft                                   │
    │                                                                 │
    │   Torque = Force × distance from center                         │
    │   Higher torque = more twisting force                           │
    │                                                                 │
    └─────────────────────────────────────────────────────────────────┘


    TORQUE UNITS:

    Unit                    Conversion
    ──────────────────────────────────────────────────────────────────
    Newton-meter (N·m)      SI unit (1 N·m = 0.737 lb-ft)
    Pound-foot (lb-ft)      Imperial unit
    Ounce-inch (oz-in)      Small motors
    Kilogram-meter (kg·m)   Older metric unit


    TYPICAL TORQUE VALUES:

    Motor Type                      Torque Range
    ──────────────────────────────────────────────────────────────────
    Small DC hobby motor            0.01-0.1 N·m
    Stepper motor (NEMA 17)         0.2-0.5 N·m
    Servo motor (RC)                0.1-0.5 N·m
    Power drill motor               1-5 N·m
    Industrial induction motor      10-1000 N·m
    Electric vehicle motor          100-500 N·m
```

### Speed (RPM)

Rotational speed measured in revolutions per minute.

```
SPEED EXPLANATION

    RPM = Revolutions Per Minute

    Relation to frequency (for AC motors):
    N_sync = (120 × f) / P

    WHERE:
    N_sync = Synchronous speed (RPM)
    f = Frequency (Hz)
    P = Number of poles (even number: 2, 4, 6, 8...)


    EXAMPLE (60 Hz AC):

    Poles       Synchronous Speed (RPM)
    ──────────────────────────────────────────────────────────────────
    2           3600
    4           1800
    6           1200
    8           900
    10          720
    12          600


    TYPICAL SPEEDS:

    Motor Type                      Speed Range (RPM)
    ──────────────────────────────────────────────────────────────────
    AC induction motor              900-3600 (depends on poles)
    Universal motor (AC/DC)         5000-20000
    Brushless DC motor              1000-10000+
    Stepper motor                   0-1000 (variable)
    Servo motor                     0-3000+
    High-speed spindle              20000-60000
```

### Power

The rate at which the motor does work.

```
POWER FORMULAS

    Mechanical Power:
    P_mech = τ × ω

    WHERE:
    P_mech = Mechanical power (Watts)
    τ = Torque (Newton-meters)
    ω = Angular velocity (radians/second)


    ANGULAR VELOCITY CONVERSION:

    ω (rad/s) = (RPM × 2π) / 60 = RPM × 0.1047

    EXAMPLE: 3000 RPM
    ω = 3000 × 0.1047 = 314 rad/s


    POWER EXAMPLE:

    Motor with: τ = 2 N·m, 3000 RPM
    ω = 3000 × 0.1047 = 314 rad/s
    P = 2 × 314 = 628 Watts


    INPUT vs OUTPUT POWER:

    P_in = V × I (electrical power input)
    P_out = τ × ω (mechanical power output)

    Efficiency (η) = P_out / P_in × 100%

    Example: P_in = 1000W, P_out = 850W
    η = 85%
```

## Motor Classification

### By Power Source

```
POWER SOURCE CLASSIFICATION

    DC MOTORS:
    ├── Run on direct current (batteries, DC power supply)
    ├── Speed controlled by voltage
    ├── Types: Brushed DC, Brushless DC (BLDC), Series, Shunt, Compound
    └── Use: Battery-powered devices, electric vehicles, robotics

    AC MOTORS:
    ├── Run on alternating current (wall outlet, generator)
    ├── Speed determined by frequency (for synchronous)
    ├── Types: Induction (squirrel cage, wound rotor), Synchronous
    └── Use: Industrial, appliances, HVAC, pumps, fans

    UNIVERSAL MOTORS:
    ├── Run on AC or DC (series-wound)
    ├── High speed (5000-20000 RPM)
    ├── High starting torque
    └── Use: Power tools, vacuum cleaners, kitchen appliances
```

### By Speed Control

```
SPEED CONTROL CLASSIFICATION

    SINGLE SPEED:
    ├── Fixed speed (determined by design)
    ├── On/Off only
    └── Use: Fans, pumps (simple)

    VARIABLE SPEED:
    ├── Speed can be adjusted
    ├── Methods: Voltage control, PWM, frequency control
    └── Use: Drills, EVs, industrial

    STEPPER:
    ├── Moves in discrete steps
    ├── Precise positioning without feedback
    └── Use: 3D printers, CNC, robotics

    SERVO:
    ├── Closed-loop speed/position control
    ├── Feedback from encoder or resolver
    └── Use: Robotics, CNC, automation
```

## Summary

1. **Electric motor** converts electrical energy into mechanical energy (rotation)

2. **Basic principle:** Current-carrying wire in magnetic field experiences force (Lorentz Force)

3. **Fleming's Left-Hand Rule** determines direction of motion (Thumb = Force, First Finger = Field, Second Finger = Current)

4. **Torque (τ)** is twisting force (τ = F × r), measured in Newton-meters

5. **Speed** is rotational velocity (RPM), related to frequency for AC motors: N = 120 × f / P

6. **Mechanical power** = Torque × Angular velocity (P = τ × ω)

7. **Electrical power** = V × I (input power)

8. **Efficiency** = P_out / P_in × 100% (typically 50-96%)

9. **Losses:** Copper (I²R), Iron (eddy current), Friction, Windage

10. **Stator** = stationary part (frame, core, windings or magnets)

11. **Rotor** = rotating part (shaft, core, conductors)

12. **Commutator** switches current direction in DC motors (mechanical)

13. **Brushes** transfer current to rotating commutator (wear item)

14. **DC motors** run on DC, speed controlled by voltage

15. **AC motors** run on AC, speed determined by frequency

16. **Universal motors** run on AC or DC (high speed, power tools)

17. **IE efficiency classes:** IE1 (standard) to IE5 (ultra premium)

18. **Over 45% of world electricity** consumed by electric motors
