# 09.05 - Sensor Reading: Analog-to-Digital Quantization, Voltage Division, and Software Linearization

## 1. The Mixed-Signal Data Acquisition Pipeline

To process environmental physical variables, a microcontroller must transition raw continuous analog signals into the discrete digital domain. This progression is handled by a dedicated hardware subsystem known as the **Analog-to-Digital Converter (ADC)**.

```text
> PHYSICAL-TO-DIGITAL HARDWARE TRANSDUCTION PIPELINE

  [ Physical Stimulus ] ──► [ Resistive Sensor ] ──► [ Voltage Divider ] ──► [ ADC Quantization ] ──► [ CPU Processing ]
     (e.g., Temperature)        (Variable R)           (Variable V_out)        (Discrete Steps)         (Linearization)

```

The data acquisition pipeline follows strict hardware conditioning stages:

1. **Transduction:** The sensor converts a physical phenomenon into a proportional analog electrical property (e.g., variation in resistance, $\Delta R$).
2. **Voltage Translation:** A voltage divider or bridge network maps the variable resistance to a variable analog voltage ($V_{\text{analog}}$).
3. **Quantization & Sampling:** The ADC samples $V_{\text{analog}}$ and bounds it against an upper analog reference voltage ($V_{\text{REF}}$), mapping it to a discrete digital integer code.

## 2. Governing Quantization and Sampling Formulas

The accuracy and granularity of a digital representation depend on two primary performance metrics: **Resolution** and **Voltage Step Size**.

### 2.1 Resolution and Step Size (Quantum Width)

The resolution of an ADC is defined by the number of bits ($N$) it utilizes to represent an analog value. The total number of discrete quantization levels available is equal to $2^N$.

The smallest continuous voltage change that the ADC can resolve is known as the **Step Size** or **Quantum Width** ($V_{\text{LSB}}$), mathematically modeled as:

$$V_{\text{LSB}} = \frac{V_{\text{REF}}}{2^N - 1}$$

Where:

* $V_{\text{LSB}}$ = **Voltage value of the Least Significant Bit**, representing the minimum voltage resolution limit, measured in Volts ($\text{V}$).
* $V_{\text{REF}}$ = **Analog reference voltage limit**, establishing the full-scale dynamic measurement range, measured in Volts ($\text{V}$).
* $N$ = **Bit resolution capacity** of the ADC (e.g., $10\text{-bit}$ or $12\text{-bit}$).

### 2.2 Ideal ADC Transfer Function

The digital integer output code ($ADC_{\text{value}}$) generated by a successive-approximation ADC tracking an instantaneous analog input voltage ($V_{\text{analog}}$) is derived using the following relationship:

$$ADC_{\text{value}} = \text{round}\left( \frac{V_{\text{analog}}}{V_{\text{REF}}} \times (2^N - 1) \right)$$

To reconstruct the continuous analog voltage from the raw digital code inside firmware scripts, apply the inverse quantization transfer function:

$$V_{\text{analog}} = ADC_{\text{value}} \times \frac{V_{\text{REF}}}{2^N - 1}$$

Where:

* $ADC_{\text{value}}$ = **Quantized digital integer output** returned by the peripheral register.
* $V_{\text{analog}}$ = **Reconstructed continuous voltage potential**, measured in Volts ($\text{V}$).

## 3. Voltage Divider Interface Engineering

Because microcontrollers evaluate voltage potentials, variable resistive sensors (such as NTC thermistors or Photoresistors) must be paired with a fixed pull-up or pull-down resistor to form a **Voltage Divider Circuit**.

```text
> PULL-DOWN RESISTIVE SENSOR INTERFACE TOPOLOGY

         Excitation Supply Voltage Rail (V_CC)
                         │
                 [ Fixed Resistor (R_1) ]
                         │
                         ├────────────────► Output Interface Voltage (V_analog)
                         │                  (To Microcontroller ADC Pin)
           [ Variable Sensor Element (R_sensor) ]
                         │
               Ground Return Rail (GND)

```

The mathematical output voltage ($V_{\text{analog}}$) delivered to the ADC pin is governed by the structural ratio of the resistances:

$$V_{\text{analog}} = V_{\text{CC}} \cdot \frac{R_{\text{sensor}}}{R_1 + R_{\text{sensor}}}$$

Where:

* $V_{\text{CC}}$ = **System excitation voltage rail** (typically $5.0\text{V}$ or $3.3\text{V}$), measured in Volts ($\text{V}$).
* $R_{\text{sensor}}$ = **Instantaneous resistance** of the active sensor, measured in Ohms ($\Omega$).
* $R_1$ = **Fixed reference pull-up resistor**, measured in Ohms ($\Omega$).

To isolate the real-time resistance of the sensor ($R_{\text{sensor}}$) from the sampled voltage value inside the processor, algebraically rearrange the divider equation:

$$R_{\text{sensor}} = R_1 \cdot \left( \frac{V_{\text{analog}}}{V_{\text{CC}} - V_{\text{analog}}} \right)$$

Substituting the quantization relationships directly eliminates the voltage terms, allowing runtime software to compute resistance directly from the raw integer code:

$$R_{\text{sensor}} = R_1 \cdot \left( \frac{ADC_{\text{value}}}{(2^N - 1) - $ADC_{\text{value}}$} \right)$$

## 4. Software Linearization Tactics

Many environmental sensors do not feature linear transfer functions. For example, Negative Temperature Coefficient (NTC) thermistors display highly non-linear, exponential changes in resistance across variations in temperature.

```text
> NON-LINEAR RESISTANCE PROFILE OF AN NTC THERMISTOR

  Resistance (R)
      ▲
      │  █
      │   █
      │    █
      │     ▀▄
      │       ▀▀▄▄
     0┼───────────┴────────────────► Temperature (T)

```

### 4.1 The Steinhart-Hart Thermodynamic Equation

To extract real-world temperatures from non-linear thermistor resistances, firmware algorithms implement the **Steinhart-Hart Equation**, a third-order polynomial model offering high-precision curve fitting:

$$\frac{1}{T} = A + B \cdot \ln(R_{\text{sensor}}) + C \cdot [\ln(R_{\text{sensor}})]^3$$

Where:

* $T$ = **Absolute temperature value**, measured in Kelvin ($\text{K}$).
* $R_{\text{sensor}}$ = **Calculated instantaneous resistance** of the thermistor, measured in Ohms ($\Omega$).
* $A, B, C$ = **Steinhart-Hart coefficients**, derived empirically from factory calibration points.

To convert the resulting absolute temperature back to standard Celsius ($T_{^\circ\text{C}}$):

$$T_{^\circ\text{C}} = T - 273.15$$

## 5. Microcontroller Integration Reference Code

The following complete embedded C code snippet demonstrates the acquisition pipeline for a $10\text{-bit}$ ADC system configured to read an NTC thermistor via a $10\text{ k}\Omega$ pull-up configuration:

```c
#include <math.h>

#define ADC_RESOLUTION  1023.0   // 2^10 - 1 discrete steps
#define V_REF           5.0      // ADC Reference potential in Volts
#define R_PULLUP        10000.0  // Fixed reference resistor value in Ohms

// Steinhart-Hart Calibration Coefficients for typical 10k NTC Thermistor
const double A = 0.001129148;
const double B = 0.000234125;
const double C = 0.0000000876741;

double read_sensor_temperature(uint16_t raw_adc) {
    // 1. Guard against boundary short-circuits to prevent divide-by-zero faults
    if (raw_adc == 0 || raw_adc >= (uint16_t)ADC_RESOLUTION) {
        return -999.9; 
    }

    // 2. Compute the instantaneous resistance of the NTC sensor element
    double r_sensor = R_PULLUP * ((double)raw_adc / (ADC_RESOLUTION - (double)raw_adc));

    // 3. Apply the Steinhart-Hart polynomial conversion model
    double ln_r = log(r_sensor);
    double r_kelvin_inv = A + (B * ln_r) + (C * ln_r * ln_r * ln_r);
    
    double temperature_kelvin = 1.0 / r_kelvin_inv;

    // 4. Transform the thermodynamic absolute units to Celsius
    double temperature_celsius = temperature_kelvin - 273.15;

    return temperature_celsius;
}

```

## 7. Summary Summary Checklist

1. **Pipeline Execution:** The data acquisition pipeline sequences real-world analog properties into proportional resistor-divider voltages, which are then digitized by an ADC.
2. **Discrete Mapping:** ADCs convert continuous external voltage ranges into a finite set of discrete integer codes governed by bit depth ($2^N$).
3. **LSB Quantum Width:** The voltage step size ($V_{\text{LSB}}$) establishes the minimum resolution threshold of an ADC; higher bit depths reduce step size to yield higher measurement precision.
4. **Reference Boundaries:** Quantized code values are directly bounded by the system's analog reference voltage ($V_{\text{REF}}$); input voltages matching or exceeding $V_{\text{REF}}$ clamp to maximum scale.
5. **Resistive Shift Mapping:** Because microcontrollers cannot evaluate changing resistance directly, voltage divider networks are required to transform varying resistance into varying voltage.
6. **Code-to-Resistance Extraction:** By substituting ADC relationships directly into divider formulas, software routines can extract a sensor's instantaneous resistance without requiring voltage calculations.
7. **Exponential Realities:** Material properties cause many sensors (such as NTC thermistors) to scale non-linearly across operational boundaries, rendering linear calibration models inaccurate.
8. **Steinhart Curve Fitting:** The third-order Steinhart-Hart polynomial equation is applied in software to linearize raw exponential resistance datasets into precise absolute thermodynamic values.
9. **Zero Partition Protection:** Boundary validation logic must be built into firmware routines to intercept full-scale short circuits ($0$ or $2^N-1$), preventing mathematical divide-by-zero execution crashes.
10. **Platform Architecture Variation:** Hardware step resolutions vary significantly across industrial device families, running from basic 10-bit educational platforms up to high-precision 16-bit silicon configurations.
