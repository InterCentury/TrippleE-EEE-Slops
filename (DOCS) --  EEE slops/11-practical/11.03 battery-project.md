# 11.03 - Battery Capacity Tester

## Project Overview

A battery capacity tester is an essential tool for anyone working with rechargeable batteries. This project allows you to measure the actual capacity (in mAh or Ah) of batteries, helping you identify weak cells, verify manufacturer claims, and determine when batteries need replacement.

This guide covers building a simple but effective battery capacity tester using an Arduino, a load resistor, a MOSFET, and a display. The tester discharges a battery at a controlled current while measuring voltage and time, calculating the total capacity discharged.

## Theory of Operation

### Capacity Measurement Principle

```
CAPACITY MEASUREMENT THEORY

    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │   CAPACITY (Ah) = Current (A) × Time (hours)                                │
    │                                                                             │
    │   For a constant current discharge:                                         │
    │   Capacity (mAh) = I_discharge (mA) × t_discharge (hours)                   │
    │                                                                             │
    │   EXAMPLE:                                                                  │
    │   Discharge at 500mA for 4 hours = 2000mAh                                  │
    │                                                                             │
    │   For varying current (real-time integration):                              │
    │   Capacity (Ah) = ∫ I(t) dt over time                                       │
    │                                                                             │
    │   Arduino method:                                                           │
    │   capacity_mAh += (current_mA × sample_interval_seconds) / 3600             │
```

## Arduino Code

### Complete Tester Code

```cpp
/*
  Battery Capacity Tester
  Measures capacity of rechargeable batteries (Li-ion, NiMH, Lead-acid)
  Discharges battery at constant current, measures voltage and time
*/

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Pin definitions
#define VOLTAGE_PIN A0      // Voltage divider input
#define MOSFET_PIN 9        // PWM control for MOSFET
#define BUTTON_PIN 2        // Start/stop button

// LCD configuration (16x2 with I2C)
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Battery parameters (adjust for your battery type)
const float CUTOFF_VOLTAGE = 3.0;     // Li-ion cutoff voltage (3.0V)
const float FULL_VOLTAGE = 4.2;       // Li-ion full voltage (4.2V)
const float DISCHARGE_CURRENT = 0.5;  // Target discharge current (Amps)

// Circuit constants
const float VOLTAGE_DIVIDER_RATIO = 2.0;  // R1=R2=10kΩ, ratio = (R1+R2)/R2 = 2
const float SHUNT_RESISTANCE = 0.1;       // Current sense resistor (Ohms) - optional

// Global variables
float batteryVoltage = 0;
float dischargeCurrent = 0;
float capacity_mAh = 0;
unsigned long startTime = 0;
unsigned long lastSampleTime = 0;
bool testing = false;
bool testComplete = false;

void setup() {
  // Initialize pins
  pinMode(MOSFET_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  
  // Start with MOSFET off
  analogWrite(MOSFET_PIN, 0);
  
  // Initialize LCD
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Battery Tester");
  lcd.setCursor(0, 1);
  lcd.print("v1.0");
  
  // Initialize serial for debugging
  Serial.begin(9600);
  Serial.println("Battery Capacity Tester Started");
  
  delay(2000);
  updateDisplay();
}

void loop() {
  // Check button press
  if (digitalRead(BUTTON_PIN) == LOW && !testing && !testComplete) {
    delay(50);  // debounce
    if (digitalRead(BUTTON_PIN) == LOW) {
      startTest();
    }
  }
  
  // Reset button after test complete
  if (digitalRead(BUTTON_PIN) == LOW && testComplete) {
    delay(50);
    if (digitalRead(BUTTON_PIN) == LOW) {
      resetTest();
    }
  }
  
  // Perform testing
  if (testing) {
    performTest();
  }
  
  delay(100);  // Main loop delay
}

void startTest() {
  testing = true;
  testComplete = false;
  capacity_mAh = 0;
  startTime = millis();
  lastSampleTime = millis();
  
  // Read initial voltage
  readVoltage();
  
  // Turn on MOSFET
  analogWrite(MOSFET_PIN, calculatePWM());
  
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Testing...");
  
  Serial.println("Test started");
  Serial.println("Time(s), Voltage(V), Current(A), Capacity(mAh)");
}

void performTest() {
  unsigned long currentTime = millis();
  float deltaTime = (currentTime - lastSampleTime) / 1000.0;  // seconds
  
  // Read voltage every second
  if (deltaTime >= 1.0) {
    readVoltage();
    readCurrent();
    
    // Update capacity (mAh)
    capacity_mAh += dischargeCurrent * (deltaTime / 3600.0) * 1000;
    
    // Update display
    updateDisplay();
    
    // Log to serial
    Serial.print((currentTime - startTime) / 1000.0);
    Serial.print(", ");
    Serial.print(batteryVoltage);
    Serial.print(", ");
    Serial.print(dischargeCurrent);
    Serial.print(", ");
    Serial.println(capacity_mAh);
    
    lastSampleTime = currentTime;
  }
  
  // Check for test completion (voltage below cutoff)
  if (batteryVoltage <= CUTOFF_VOLTAGE) {
    endTest();
  }
  
  // Adjust PWM to maintain constant current (if using current sense)
  analogWrite(MOSFET_PIN, calculatePWM());
}

void endTest() {
  testing = false;
  testComplete = true;
  
  // Turn off MOSFET
  analogWrite(MOSFET_PIN, 0);
  
  // Calculate test duration
  float testTime = (millis() - startTime) / 3600000.0;  // hours
  
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Test Complete!");
  lcd.setCursor(0, 1);
  lcd.print("Cap: ");
  lcd.print(capacity_mAh);
  lcd.print(" mAh");
  
  Serial.println("Test complete");
  Serial.print("Total capacity: ");
  Serial.print(capacity_mAh);
  Serial.println(" mAh");
  Serial.print("Test duration: ");
  Serial.print(testTime);
  Serial.println(" hours");
}

void resetTest() {
  testComplete = false;
  capacity_mAh = 0;
  batteryVoltage = 0;
  dischargeCurrent = 0;
  
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Battery Tester");
  lcd.setCursor(0, 1);
  lcd.print("Ready");
  
  delay(1000);
  updateDisplay();
  
  Serial.println("Test reset");
}

void readVoltage() {
  int raw = analogRead(VOLTAGE_PIN);
  float voltage_at_divider = (raw / 1023.0) * 5.0;
  batteryVoltage = voltage_at_divider * VOLTAGE_DIVIDER_RATIO;
}

void readCurrent() {
  // For constant current using resistor load (no feedback):
  // Current = Battery voltage / Load resistance
  // This assumes constant resistance load, not true constant current
  
  // For constant current using sense resistor:
  // int currentRaw = analogRead(CURRENT_PIN);
  // float currentVoltage = (currentRaw / 1023.0) * 5.0;
  // dischargeCurrent = currentVoltage / SHUNT_RESISTANCE;
  
  // Simple method (assuming fixed load resistor):
  float loadResistance = 4.7;  // Ohms (your load resistor value)
  dischargeCurrent = batteryVoltage / loadResistance;
  
  // Limit to safe maximum
  if (dischargeCurrent > 2.0) dischargeCurrent = 2.0;
}

int calculatePWM() {
  // Simple constant current control using PID (optional)
  // For basic tester, just use fixed PWM or on/off control
  // Return 0-255 PWM value
  
  // Simple on/off (bang-bang) control:
  if (testing && batteryVoltage > CUTOFF_VOLTAGE) {
    return 255;  // Full on
  } else {
    return 0;
  }
  
  // For constant current with sense resistor:
  // float error = TARGET_CURRENT - dischargeCurrent;
  // int pwm = constrain(previousPWM + error * Kp, 0, 255);
  // return pwm;
}

void updateDisplay() {
  lcd.setCursor(0, 0);
  lcd.print("V:");
  lcd.print(batteryVoltage, 2);
  lcd.print("V  I:");
  lcd.print(dischargeCurrent, 2);
  lcd.print("A ");
  
  lcd.setCursor(0, 1);
  lcd.print("Cap:");
  lcd.print(capacity_mAh, 0);
  lcd.print("mAh ");
  
  // Show test status
  if (testing) {
    unsigned long minutes = (millis() - startTime) / 60000;
    lcd.print(minutes);
    lcd.print("m");
  }
}
```

## Calibration

### Voltage Calibration

```
VOLTAGE CALIBRATION PROCEDURE

    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │   STEP 1: Measure known voltage (e.g., new Li-ion cell at 4.20V)            │
    │                                                                             │
    │   STEP 2: Read raw ADC value from Arduino                                   │
    │                                                                             │
    │   STEP 3: Calculate correction factor                                       │
    │                                                                             │
    │   Correction = True Voltage / Measured Voltage                              │
    │                                                                             │
    │   STEP 4: Update code:                                                      │
    │   voltage = raw_reading × (5.0 / 1023.0) × divider_ratio × correction       │
    │                                                                             │
    │   EXAMPLE:                                                                  │
    │   True voltage = 4.20V                                                      │
    │   Measured = 4.05V                                                          │
    │   Correction = 4.20 / 4.05 = 1.037                                          │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘


    CURRENT CALIBRATION

    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │

    │   ├── Connect multimeter in series with battery and load                  │
```

## Formulas Quick Reference

| Formula | Purpose |
|---------|---------|
| Capacity (Ah) = I (A) × t (h) | Basic capacity calculation |
| Capacity (mAh) = I (mA) × t (h) | Milliampere-hour calculation |
| capacity_mAh += current_mA × (Δt_seconds / 3600) | Integration for varying current |
| V_out = V_battery × (R2 / (R1 + R2)) | Voltage divider output |
| V_battery = V_ADC × ((R1 + R2) / R2) | Battery voltage from ADC |
| R_load = V_battery / I_discharge | Load resistor selection |
| P_resistor = V_battery × I_discharge | Power dissipation in load resistor |
| V_sense = I × R_sense | Current sense voltage |
| ADC_value = (V_in × 1023) / 5.0 | Analog to digital conversion |
| test_duration_hours = (end_time - start_time) / 3600000 | Test duration calculation |

## Summary

1. **Project purpose:** Measure actual capacity of rechargeable batteries (Li-ion, NiMH, lead-acid)

2. **Principle:** Discharge at constant current, measure voltage and time, calculate capacity (mAh = I × t)

3. **Components:** Arduino, LCD, MOSFET, load resistor, voltage divider, push button

4. **Load resistor selection:** R = V_battery / I_discharge (4.7Ω for 0.9A Li-ion, 10Ω for 1.2A lead-acid)

5. **Power rating:** P = V × I (use 2-3× safety margin, 10W resistor for 0.9A Li-ion, 20W for 1.2A lead-acid)

6. **Voltage divider:** Two 10kΩ resistors (ratio 2:1) to measure up to 10V batteries

7. **MOSFET selection:** Logic-level N-channel (IRLZ44N for 5V gate drive, IRFZ44N for >8V gate)

8. **Gate resistor:** 100-220Ω to limit current, 10kΩ pulldown to prevent floating gate

9. **Discharge current:** 0.5C recommended for accurate capacity measurement (1C for 1 hour test)

10. **Cutoff voltages:** Li-ion (3.0V), NiMH (1.0V per cell), Lead-acid (10.5V for 12V)

11. **Safety:** NEVER leave unattended, load resistor gets VERY hot, monitor battery temperature

12. **Calibration:** Use known voltage source to calibrate voltage divider readings

13. **Integration method:** capacity_mAh += current_mA × (Δt_seconds / 3600)

14. **Data interpretation:** 90-100% (good), 70-90% (marginal), 50-70% (weak), <50% (failed)

15. **Troubleshooting:** No voltage reading (check connections), MOSFET not turning on (check gate drive), inaccurate measurement (calibrate)

16. **Enhancements:** SD card logging, constant current control (PID), multi-cell testing, graphical display, WiFi remote monitoring
