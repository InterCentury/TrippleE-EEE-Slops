# 11.04 - Capstone Project: Smart Temperature-Controlled Cooling System

## 1. System Architecture and Objective

This project integrates analog signal acquisition, mathematical data translation, and high-current power switching into a singular closed-loop control system. The objective is to construct an autonomous cooling unit that dynamically adjusts the rotational velocity (RPM) of a DC fan in direct proportion to the ambient thermal load, minimizing acoustic noise and power consumption when maximum cooling is not required.

The architecture relies on three primary stages:

1. **Sensing Stage:** An NTC (Negative Temperature Coefficient) Thermistor in a voltage divider network translates physical heat into an analog voltage.
2. **Processing Stage:** A microcontroller (MCU) digitizes the voltage, calculates the absolute temperature using the Steinhart-Hart equation, and maps this value to a PWM control signal.
3. **Actuation Stage:** A logic-level MOSFET acts as a low-side switch, amplifying the MCU's weak PWM signal to drive the high-current inductive DC motor.

## 2. Temperature Acquisition: The NTC Thermistor

Unlike linear sensors (e.g., LM35), an NTC thermistor's electrical resistance decreases exponentially as temperature increases. It requires a fixed series resistor ($R_{\text{fixed}}$, typically $10\text{k}\Omega$) to form a voltage divider so the MCU's Analog-to-Digital Converter (ADC) can measure the voltage drop.

### 2.1 The Voltage Divider Equation

To determine the dynamic resistance of the thermistor ($R_t$) based on the raw ADC value:

$$V_{\text{out}} = V_{\text{cc}} \cdot \left( \frac{R_t}{R_t + R_{\text{fixed}}} \right)$$

Translated into ADC integer logic (assuming a 10-bit ADC where $V_{\text{cc}} = 1023$):

$$R_t = R_{\text{fixed}} \cdot \left( \frac{1023}{\text{ADC}_{\text{val}}} - 1 \right)$$

### 2.2 The Steinhart-Hart Equation

The non-linear relationship between the thermistor's resistance and physical temperature is resolved using the simplified Beta ($\beta$) parameter equation:

$$\frac{1}{T} = \frac{1}{T_0} + \frac{1}{\beta} \ln\left(\frac{R_t}{R_0}\right)$$

Where:

* $T$ = Absolute temperature in Kelvin ($\text{K}$).
* $T_0$ = Nominal room temperature in Kelvin ($298.15\text{ K}$ or $25^\circ\text{C}$).
* $R_0$ = Nominal resistance at $25^\circ\text{C}$ (typically $10,000\text{ }\Omega$).
* $\beta$ = The Beta coefficient of the thermistor (typically $3950$ to $4000$, found in the datasheet).

To convert the resulting Kelvin value to Celsius:


$$T_{^\circ\text{C}} = T - 273.15$$

## 3. Power Actuation: MOSFET Low-Side Switching

The MCU cannot drive the DC fan directly. We utilize an N-Channel Logic-Level MOSFET (e.g., IRLZ44N) to handle the heavy current load, protected by a Flyback Diode to prevent inductive voltage spikes from destroying the silicon.

```text
> HARDWARE WIRING TOPOLOGY

[12V Power Supply] ────────┬─────────────────────────────┐
                           │                             │
                        [Fan +]                       [Cathode]
                        DC FAN                      1N4001 DIODE
                        [Fan -]                       [Anode]
                           │                             │
                           ├─────────────────────────────┘
                           │
                      [Drain (D)]
                       MOSFET
[MCU PWM Pin] ──[Gate (G)] 
                      [Source (S)]
                           │
[MCU GND] ─────────────────┴──────────────────────── [12V Supply GND]

```

*Crucial Design Rule:* The MCU Ground and the 12V Supply Ground MUST be physically tied together. If the grounds are isolated, the MOSFET gate will float, and the transistor will fail to switch.

## 4. Control Logic: Linear PWM Mapping

To achieve proportional cooling, the MCU maps the calculated temperature variable directly to the 8-bit PWM duty cycle range ($0$ to $255$).

We define two thermal thresholds:

* $T_{\text{min}}$: The temperature below which the fan remains completely OFF ($0\text{ PWM}$).
* $T_{\text{max}}$: The temperature at which the fan runs at $100\%$ maximum velocity ($255\text{ PWM}$).

The mathematical linear interpolation (slope-intercept formula) for any temperature $T$ between these thresholds is:

$$\text{PWM} = \left( \frac{T - T_{\text{min}}}{T_{\text{max}} - T_{\text{min}}} \right) \cdot 255$$

## 5. Bare-Metal C++ Firmware

```cpp
#include <Arduino.h>

// Hardware Pins
const int THERMISTOR_PIN = A0;
const int FAN_PWM_PIN = 9;

// Thermistor Calibration Constants
const float SERIES_RESISTOR = 10000.0;
const float NOMINAL_RESISTANCE = 10000.0;
const float NOMINAL_TEMP = 298.15; // 25 C in Kelvin
const float B_COEFFICIENT = 3950.0;

// Thermal Thresholds (Celsius)
const float TEMP_MIN = 30.0; // Fan OFF below this
const float TEMP_MAX = 50.0; // Fan 100% above this

void setup() {
    pinMode(FAN_PWM_PIN, OUTPUT);
    analogWrite(FAN_PWM_PIN, 0); // Initialize OFF
}

float readTemperature() {
    int adc_val = analogRead(THERMISTOR_PIN);
    
    // Prevent divide-by-zero on hardware fault
    if (adc_val == 0) return 0; 

    // 1. Calculate Resistance
    float resistance = SERIES_RESISTOR * ((1023.0 / adc_val) - 1.0);

    // 2. Apply Steinhart-Hart (Beta Equation)
    float steinhart = resistance / NOMINAL_RESISTANCE; 
    steinhart = log(steinhart);                        
    steinhart /= B_COEFFICIENT;                        
    steinhart += 1.0 / NOMINAL_TEMP;                   
    steinhart = 1.0 / steinhart;                       
    
    // 3. Convert to Celsius
    return steinhart - 273.15;                         
}

void loop() {
    float current_temp = readTemperature();
    int pwm_output = 0;

    // Boundary Logic & Linear Mapping
    if (current_temp <= TEMP_MIN) {
        pwm_output = 0;
    } 
    else if (current_temp >= TEMP_MAX) {
        pwm_output = 255;
    } 
    else {
        // Map temperature range to PWM range (0-255)
        pwm_output = (int)(((current_temp - TEMP_MIN) / (TEMP_MAX - TEMP_MIN)) * 255.0);
    }

    analogWrite(FAN_PWM_PIN, pwm_output);
    delay(500); // Sample rate limitation for thermal stability
}

```

## 6. Thermal Dynamics (Newton's Law of Cooling)

To predict how fast the project will cool a given heat source, we reference Newton's Law of Cooling, which states that the rate of heat loss of a body is directly proportional to the difference in temperatures between the body and its surroundings.

$$\frac{dT}{dt} = -k(T - T_{\text{env}})$$

Where:

* $\frac{dT}{dt}$ = Rate of change of temperature.
* $k$ = Cooling constant (dependent on the surface area and the airflow $Q$ provided by the fan).
* $T$ = Current temperature of the object.
* $T_{\text{env}}$ = Ambient environmental temperature.

By applying PWM fan control, we are dynamically altering the cooling constant $k$ in real-time. As $T$ approaches $T_{\text{env}}$, the MCU reduces the PWM duty cycle, lowering $k$ and allowing the temperature to smoothly asymptote to the target threshold without aggressive thermal oscillation.

## 7. Project Summary Checklist

1. **Analog Non-Linearity:** Understand that thermistors do not output linear voltages. The Steinhart-Hart logarithmic equation is strictly required to extract accurate Celsius data.
2. **Ground Unity:** Verify with a multimeter that the MCU logic ground and the heavy 12V motor power ground share a continuous, low-resistance path.
3. **Inductive Protection:** Visually confirm the orientation of the 1N4001 flyback diode. The striped cathode must face the positive supply voltage. Reversing this will cause a direct short circuit.
4. **Saturation Constraints:** The mapping algorithm must include hard constraints (e.g., `if temp > TEMP_MAX`) to prevent the calculated PWM integer from exceeding $255$, which would cause register overflow and result in the fan shutting off at maximum heat.
5. **Sample Rate Limiting:** Thermal mass takes time to change state. Never sample the thermistor at the MCU's maximum clock speed (e.g., 16 MHz); use a delay to sample at $2\text{Hz}$ or $1\text{Hz}$ to prevent the fan from reacting to micro-fluctuations in electrical noise.
