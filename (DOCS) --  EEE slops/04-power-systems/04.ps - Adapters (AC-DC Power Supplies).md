# 04 - Power Adapters (AC-DC Power Supplies)

## What is a Power Adapter?

A power adapter (also called AC adapter, power supply, wall wart, or power brick) is an external device that converts alternating current (AC) from a wall outlet into the direct current (DC) required by electronic devices. It sits between the wall outlet and the device, providing the correct voltage, current, and often regulating the output for stable operation.

Power adapters are ubiquitous in modern life—every laptop, phone charger, router, modem, printer, and countless other devices uses one. They allow devices to be smaller, lighter, and safer by moving the bulky, heat-generating power conversion components outside the main device enclosure.

## Basic Principles

## Types of Power Adapters

### Linear Power Supplies

The older, simpler design using a mains-frequency transformer.

```
LINEAR POWER SUPPLY

    ┌────────────────────────────────────────────────────────────────────┐
    │                                                                    │
    │   ┌────────────────────────────────────────────────────────────┐   │
    │   │       ████████████████████████████████████████████████     │   │
    │   │       ██           Linear Power Supply              ██     │   │
    │   │       ██            (Wall Wart - Heavy)             ██     │   │
    │   │       ████████████████████████████████████████████████     │   │
    │   │                                                            │   │
    │   │   AC in ──► Transformer ──► Rectifier ──► Filter ──► DC    │   │
    │   │             (bulky iron     (diodes)    (cap)    out       │   │
    │   │              core)                                         │   │
    │   │                                                            │   │
    │   └────────────────────────────────────────────────────────────┘   │
    │                                                                    │
    └────────────────────────────────────────────────────────────────────┘

    WAVEFORM PROGRESSION:

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   After transformer:   After rectifier:    After filter:    │
    │   ╱╲    ╱╲             ╱╲╱╲╱╲             ───────_          │
    │  ╱  ╲  ╱  ╲           ╱    ╱               │    │           │
    │ ╱    ╲╱    ╲         ╱    ╱                │    │           │
    │                        (full-wave)        small ripple      │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘

    CHARACTERISTICS:
    ├── Heavy (due to iron core transformer)
    ├── Large size
    ├── Inefficient (40-60% typical)
    ├── Generates significant heat
    ├── Very low output noise (<1mV ripple)
    ├── Excellent regulation
    ├── Simple design (easy to repair)
    ├── No electromagnetic interference (EMI)
    ├── Low cost for low power (<5W)
    └── Becoming rare (replaced by switching supplies)

    TYPICAL APPLICATIONS:
    ├── Audio equipment (low noise requirement)
    ├── Laboratory power supplies (precision)
    ├── Medical devices (low EMI)
    ├── Test equipment
    └── Vintage electronics (original design)
```

### Switching Power Supplies (SMPS)

The modern standard; small, lightweight, efficient.

```
SWITCHING POWER SUPPLY (SMPS)

    ┌───────────────────────────────────────────────────────────────────┐
    │                                                                   │
    │   ┌───────────────────────────────────────────────────────────┐   │
    │   │  ████████████████████████████████████████████████         │   │
    │   │  ██           Switching Power Supply           ██         │   │
    │   │  ██              (SMPS - Light)                ██         │   │
    │   │  ████████████████████████████████████████████████         │   │
    │   │                                                           │   │
    │   │   AC in ──► Rectify ──► Filter ──► Switch ──► Transformer │   │
    │   │            (AC→DC)      (cap)      (MOSFET)  (high freq)  │   │
    │   │                                                     │     │   │
    │   │                        ┌────────────────────────────┘     │   │
    │   │                        │                                  │   │
    │   │                        ▼                                  │   │
    │   │                  Rectify ──► Filter ──► DC out            │   │
    │   │                  (diodes)      (cap)                      │   │
    │   │                                                           │   │
    │   └───────────────────────────────────────────────────────────┘   │
    │                                                                   │
    └───────────────────────────────────────────────────────────────────┘

    WHY HIGH FREQUENCY?

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Transformer size is INVERSELY proportional to frequency   │
    │                                                             │
    │   60 Hz transformer:   large, heavy (iron core)             │
    │   50 kHz transformer:  tiny, light (ferrite core)           │
    │   1 MHz transformer:   extremely tiny                       │
    │                                                             │
    │   Higher frequency = smaller transformer = smaller adapter  │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘

    CHARACTERISTICS:
    ├── Lightweight (small high-frequency transformer)
    ├── Compact size
    ├── Efficient (70-90% typical)
    ├── Cool operation (less wasted heat)
    ├── Higher output noise (10-100mV ripple)
    ├── Wide input range (90-264V AC, works worldwide)
    ├── Complex design (harder to repair)
    ├── Generates EMI (requires filtering)
    ├── Power factor correction (PFC) in quality units
    └── Dominates modern market (phones, laptops, etc.)

    TYPICAL APPLICATIONS:
    ├── Phone chargers
    ├── Laptop power supplies
    ├── Desktop computer PSUs
    ├── LED drivers
    ├── TV power supplies
    ├── USB chargers
    └── Almost all consumer electronics
```

## Adapter Specifications

### Input Specifications

What the adapter draws from the wall outlet.

```
INPUT RATINGS

    Voltage:
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Fixed input:  120V AC (US/Canada)                         │
    │                 230V AC (Europe, Asia)                      │
    │                                                             │
    │   Wide input:   100-240V AC (universal, switching only)     │
    │                 90-264V AC (full range)                     │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘

    Frequency:
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Fixed:        50 Hz or 60 Hz (linear only)                │
    │   Universal:    50-60 Hz (most switching)                   │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘

    Current:
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Input current rating (e.g., 0.5A, 1.2A)                   │
    │   Usually lower than output current (because higher voltage)│
    │                                                             │
    │   Example: 12V, 3A output (36W)                             │
    │            Input: 120V, 0.5A (60W) → efficiency = 36/60=60% │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### Polarity Identification

```
HOW TO IDENTIFY POLARITY

    METHOD 1: Look for the polarity symbol on adapter label:

    Center Positive:                 Center Negative:
    ──(⊕──┐                          ──(⊖──┐
        │                                  │
    ──(⊖──┘                          ──(⊕──┘

    METHOD 2: Look for markings on the device near the power jack

    METHOD 3: Use a multimeter:

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   1. Set multimeter to DC volts (20V range)                │
    │   2. Connect black lead to outer barrel (use paper clip)   │
    │   3. Connect red lead to center pin                        │
    │   4. If reading is POSITIVE → center positive              │
    │   5. If reading is NEGATIVE → center negative              │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘

    METHOD 4: Check device documentation

    WARNING: Never assume polarity! Always verify.
    Wrong polarity can destroy electronics instantly!
```

### What Happens When Mismatched?

```
VOLTAGE MISMATCH

    Adapter voltage TOO LOW (e.g., 5V adapter on 12V device):
    ├── Device may not power on (undervoltage lockout)
    ├── May operate erratically (brownout)
    ├── Motor may not start (stall, overheat)
    ├── Unlikely to cause permanent damage
    └── Adapter may be overloaded (device tries to draw more current)

    Adapter voltage TOO HIGH (e.g., 12V adapter on 5V device):
    ├── IMMEDIATE DAMAGE to device!
    ├── Voltage regulator burns out (overvoltage)
    ├── Capacitors explode (rated for lower voltage)
    ├── ICs destroyed (exceed absolute maximum)
    ├── Magic smoke released (permanent failure)
    └── REPAIR OFTEN IMPOSSIBLE (multiple components failed)


    CURRENT MISMATCH

    Adapter current TOO LOW (e.g., 1A adapter on 2A device):
    ├── Adapter overheats (exceeds design current)
    ├── Output voltage drops (brownout, device resets)
    ├── Thermal shutdown may activate (cycles on/off)
    ├── Adapter may fail permanently (burned components)
    ├── Fire hazard if no thermal protection
    └── Device may behave erratically (low voltage)

    Adapter current HIGHER than needed (e.g., 3A adapter on 1A device):
    ├── PERFECTLY SAFE
    ├── Device draws only 1A (what it needs)
    ├── Adapter runs cool (lightly loaded)
    ├── Extra capacity for future upgrades
    └── Only downside: slightly larger/heavier (usually fine)


    POLARITY MISMATCH

    Reverse polarity applied to device:
    ├── Protection diode (if present) shorts → blows fuse or burns
    ├── No protection diode → damage to entire circuit
    ├── Electrolytic capacitors reverse-biased → may explode
    ├── ICs reverse-biased → internal damage
    └── RESULT: Almost certain damage, often catastrophic


    CONNECTOR SIZE MISMATCH

    2.5mm ID plug → 2.1mm ID jack:
    ├── Plug too large for center pin
    ├── May not make contact (intermittent)
    ├── Forcing damages jack
    └── Risk of short circuit (center pin touches barrel)

    2.1mm ID plug → 2.5mm ID jack:
    ├── Plug too small, center pin loose
    ├── Intermittent connection
    ├── Device may power cycle (brownout)
    └── Arcing can damage connector
```

## Common Problems and Troubleshooting

### Problem 1: Adapter Overheating

```
SYMPTOMS:
├── Adapter very hot to touch (>60°C)
├── Thermal shutdown (device turns off, then back on)
├── Reduced output voltage under load
├── Melting case or smell

CAUSES:
├── Overload (device draws more current than adapter rated for)
├── Poor ventilation (covered or enclosed space)
├── High ambient temperature (summer, near radiator)
├── Internal component failure (capacitors drying out)
├── Short circuit in device or cable
├── Adapter undersized for continuous use

DIAGNOSIS:
├── Measure device current draw (compare to adapter rating)
├── Check for blocked ventilation
├── Feel for hot spots (indicates internal failure)
├── Test with different device (if available)
├── Measure output voltage (should be within ±5% at rated load)

SOLUTIONS:
├── Reduce load (use higher current adapter)
├── Improve ventilation (move to open area)
├── Add small fan for cooling
├── Replace adapter (if internal failure)
├── Use adapter rated for continuous duty
├── For hot-running linear supplies: normal operation (inefficient)
```

### Problem 2: No Output

```
SYMPTOMS:
├── Device won't power on
├── Multimeter reads 0V at adapter output
├── No LED indicator (if present)

CAUSES:
├── Internal fuse blown (overload or surge)
├── Input cord damaged (break in wire)
├── Output cord damaged (break in wire)
├── Failed internal component
├── Thermal fuse tripped (needs cool-down)
├── Loose connection inside adapter

DIAGNOSIS:
├── Check input voltage (wall outlet working?)
├── Test with known working device
├── Measure output voltage with multimeter (no load)
├── Wiggle cords (look for intermittent connection)
├── Check for physical damage
├── Listen for rattling (loose internal components)

SOLUTIONS:
├── Replace fuse (if accessible and user-replaceable)
├── Repair broken cord (cut, splice, or replace)
├── Let cool if thermal protection tripped (30 minutes)
├── Replace adapter (most cost-effective for <$50)
├── Repair only if high-value or specialty adapter
├── For laptop adapters: consider OEM replacement
```

### Problem 3: Intermittent Operation

```
SYMPTOMS:
├── Device powers on and off randomly
├── Slight movement causes loss of power
├── Works sometimes, fails others

CAUSES:
├── Loose connection at connector (worn or bent)
├── Broken wire inside cord (flexing fatigue)
├── Dirty or oxidized connector contacts
├── Cold solder joint inside adapter
├── Loose AC plug in wall outlet (worn outlet)

DIAGNOSIS:
├── Wiggle cord at both ends while monitoring output
├── Check connector fit (should be snug, not loose)
├── Inspect for bent or broken pins
├── Test with different outlet
├── Check for cable damage (bulges, kinks, exposed wire)

SOLUTIONS:
├── Replace connector (if user-replaceable type)
├── Replace entire adapter (if cord is integral)
├── Clean contacts with contact cleaner
├── Resolder loose joints (if experienced)
├── Tighten or replace wall outlet
├── Use cable strain relief

TEMPORARY FIX (not recommended):
├── Position cord in specific orientation (will fail again)
└── Better to replace adapter
```

### Problem 4: Excessive Noise (Whining or Buzzing)

```
SYMPTOMS:
├── Audible high-frequency whine (5-20 kHz)
├── 50/60 Hz hum (linear supplies)
├── Buzzing or rattling sound

CAUSES (Switching supplies):
├── Loose ferrite transformer core (vibrating)
├── Magnetostriction (core expanding/contracting)
├── Capacitor aging (ceramic capacitors can be piezoelectric)
├── Load too light (burst mode operation)
├── Load too heavy (near overload)

CAUSES (Linear supplies):
├── Loose transformer laminations (buzzing at 50/60 Hz)
├── DC offset on primary (saturates core)
├── Loose mounting hardware
├── Normal operation (some hum is acceptable)

DIAGNOSIS:
├── Identify frequency (low hum = 50/60 Hz, high whine = switching)
├── Change load (some supplies whine at light load)
├── Press on components with insulated tool (stops? = loose)
├── Compare to identical adapter (normal vs abnormal)

SOLUTIONS:
├── Replace adapter (if whine is excessive or annoying)
├── Potting compound (stops vibration, not user serviceable)
├── Add load resistor (for light-load whine - not recommended)
├── For transformer hum: tighten bolts if accessible
├── Some whine is normal and harmless (just annoying)

WHEN TO WORRY:
├── Sudden change in noise level (pre-failure indicator)
├── Noise accompanied by overheating or smell
├── Arcing or sizzling sounds (dangerous!)
└── Otherwise, annoying noise usually not dangerous
```

## Summary

1. **Power adapter** converts AC from wall to DC for electronic devices

2. **Three functions:** voltage conversion, rectification (AC→DC), regulation/filtering

3. **Linear supply:** heavy, inefficient (40-60%), very low noise, simple

4. **Switching supply (SMPS):** light, efficient (70-90%), some noise, universal input

5. **Higher switching frequency = smaller transformer = smaller adapter**

6. **Adapter must match:** voltage (exact), current (≥ requirement), polarity, connector

7. **Voltage too high** = destroys device (magic smoke, permanent damage)

8. **Voltage too low** = device won't work (usually safe)

9. **Current too low** = adapter overheats, fails (fire hazard)

10. **Current higher than needed** = perfectly safe (device draws only what it needs)

11. **Polarity wrong** = almost certain damage (protection diode may save it)

12. **Barrel connectors:** 5.5×2.1mm most common; 2.1mm vs 2.5mm look similar but not compatible

13. **USB standards:** 5V original; USB-PD negotiates 5V-48V up to 240W

14. **USB-PD requires USB-C to USB-C cable** (and device/charger support)

15. **Universal adapters:** adjustable voltage, interchangeable tips – convenient but risk of wrong settings

16. **Efficiency standards:** Level VI requires 85-90% efficiency, <0.1W no-load

17. **Vampire power:** adapters draw power even when nothing connected (unplug when not in use)

18. **Safety certifications:** UL, CE, TUV, etc. indicate testing; uncertified = fire hazard

19. **Red flags:** too hot, burning smell, smoke, arcing sounds → unplug immediately

20. **Quality matters:** cheap adapters may lack safety features, overheat, catch fire
