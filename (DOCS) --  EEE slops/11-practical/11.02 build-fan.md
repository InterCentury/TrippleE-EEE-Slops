# 11.02 - How to Build a Simple Electric Fan

## Project Overview

Building a simple electric fan is an excellent introductory project for understanding basic DC motor operation, circuit design, and mechanical assembly. This project uses a small DC motor, a fan blade, a power source, and a switch to create a functional desktop fan.

This guide covers everything from component selection to assembly, troubleshooting, and safety considerations. By the end, you'll have a working fan and a solid understanding of how small DC motors are controlled.

```
    VOLTAGE DIVIDER FORMULA (for potentiometer speed control):

    V_motor = V_battery × (R_pot_bottom / R_pot_total)

    Example: 6V battery, 10kΩ pot at 50% (R_bottom = 5kΩ)
    V_motor = 6 × (5/10) = 3V (approximately half speed)

    WARNING: Potentiometers are NOT rated for motor current!
    Use only for voltage reference with transistor driver.
    For direct speed control, use PWM from microcontroller.
```

```
    │                                  └──────┬──────┘                            │
    │                                         │                                   │
    │                                         │                                   │
    │                                    ┌────┴────┐                              │
    │                                    │  Motor  │                              │
    │                                    │   (+)   │                              │
    │                                    └────┬────┘                              │
    │                                         │                                   │
    │                                    ┌────┴────┐                              │
    │                                    │  Motor  │                              │
    │                                    │   (-)   │                              │
    │                                    └────┬────┘                              │
    │                                         │                                   │
    │   BATTERY (-) ──────────────────────────┘                                   │
    │   (Black)                                                                   │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘


    TRANSISTOR CALCULATIONS:

    Base current (I_B) = (V_control - 0.7) / R_base

    Example: V_control = 5V (Arduino), R_base = 1kΩ
    I_B = (5 - 0.7) / 1000 = 4.3 / 1000 = 0.0043A = 4.3mA

    Collector current (I_C) = β × I_B
    β (2N2222) ≈ 100
    I_C_max = 100 × 0.0043 = 0.43A (430mA) → enough for small motor

    For larger motor (1A+), use Darlington pair (TIP120) or MOSFET.
```

### Performance Measurements

```
MEASUREMENT FORMULAS

    FAN SPEED (RPM):
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │   Using strobe light (or optical tachometer):                             │
    │   RPM = Measured rotations per minute                                      │
    │                                                                             │
    │   Using multimeter with frequency function:                                │
    │   RPM = (Frequency × 60) / (Number of poles)                              │
    │                                                                             │
    │   Approximate speed from voltage:                                          │
    │   RPM ≈ (Voltage applied × 1000) for 130-size motor                       │
    │   3V → 3000 RPM, 6V → 6000 RPM, 9V → 9000 RPM                           │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘


    AIRFLOW (CFM - Cubic Feet per Minute):
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │   Rough estimate for small fan:                                            │
    │   CFM ≈ (Blade diameter in inches²) × (RPM / 1000) × 0.1                   │
    │                                                                             │
    │   Example: 3" diameter blade, 6000 RPM                                    │
    │   CFM ≈ (9) × 6 × 0.1 = 5.4 CFM                                           │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘


    CURRENT CONSUMPTION:
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │   Measure with multimeter in series:                                       │
    │   I = V / R (using shunt resistor) or use ammeter function                │
    │                                                                             │    │   Expected values:                                                         │
    │   ├── No load (fan only): 100-200mA                                       │
    │   ├── With light load: 150-300mA                                          │
    │   └── Stall (blade blocked): 500-1500mA (brief only!)                    │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘

```

```
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │   PROBLEM: Motor doesn't spin                                              │
    │   ├── Check battery voltage (replace if low)                              │
    │   ├── Check switch continuity (ON position)                               │
    │   ├── Check wire connections (solder joints)                              │
    │   ├── Check motor polarity (reverse wires)                                │
    │   └── Check for mechanical obstruction (blade stuck)                      │
    │                                                                             │
    │   PROBLEM: Motor spins slowly                                              │
    │   ├── Low battery voltage (replace batteries)                             │
    │   ├── Poor connections (high resistance)                                  │
    │   ├── Blade too large or heavy                                            │
    │   ├── Bearings worn (motor aging)                                         │
    │   └── Increase voltage (use 9V instead of 6V)                            │
    │                                                                             │
    │   PROBLEM: Excessive vibration                                             │
    │   ├── Blade out of balance (add small weight to light side)               │
    │   ├── Blade not centered on shaft                                         │
    │   ├── Motor mount loose (tighten screws/zip ties)                         │
    │   ├── Shaft bent (replace motor)                                          │
    │   └── Base not stable (add rubber feet)                                   │
    │                                                                             │
    │   PROBLEM: Motor gets too hot                                              │
    │   ├── Too much voltage (use 6V instead of 9V)                             │
    │   ├── Blade too heavy (use smaller blade)                                 │
    │   ├── Binding bearings (add small drop of oil)                            │
    │   ├── Extended run time (add heat sink)                                   │
    │   └── Motor stalled (remove obstruction)                                  │
    │                                                                             │
    │   PROBLEM: Battery drains quickly                                          │
    │   ├── Motor drawing too much current (reduce load)                        │
    │   ├── Poor quality batteries (use alkaline or NiMH)                       │
    │   ├── Short circuit (check wiring)                                        │
    │   └── Switch left ON (turn off when not in use)                          │
```

## Formulas Quick Reference

| Formula | Purpose |
|---------|---------|
| V_motor = V_battery × (R2/(R1+R2)) | Voltage divider speed control |
| I_B = (V_control - 0.7) / R_base | Transistor base current |
| I_C = β × I_B | Transistor collector current |
| P = V × I | Power consumption |
| RPM ≈ Voltage × 1000 | Approximate motor speed |
| CFM ≈ (D²) × (RPM/1000) × 0.1 | Rough airflow estimate |
| Battery life (hours) = mAh / mA | Runtime calculation |

## Summary

1. **Project goal:** Build a functional desktop fan using a DC motor, battery, and switch

2. **Motor type:** 130-size DC motor (3-12V, 1000-10000 RPM, 100-500mA)

3. **Power options:** 4×AA (6V) for balance, 9V for speed, USB (5V) for rechargeable

4. **Battery life:** 2000mAh AA battery at 150mA = ~13 hours runtime

5. **Stall current** can reach 1A+ (avoid prolonged stall)

6. **Basic circuit:** Battery → Switch → Motor → Battery (series connection)

7. **Speed control:** Potentiometer needs transistor driver (motor current too high for pot)

8. **Transistor driver:** NPN (2N2222 for <500mA, TIP120 for >1A)

9. **Base size:** Minimum 4"×4" for stability

10. **Fan blade:** Press-fit onto motor shaft (2mm diameter typical)

11. **Testing procedure:** Visual inspection → continuity test → brief power-on → continuous operation

12. **Safety:** Keep fingers away from spinning blade, monitor motor temperature

13. **Troubleshooting:** No spin (check voltage/polarity), slow spin (low voltage/load), vibration (balance blade), heat (reduce voltage/load)

14. **Enhancements:** Speed control, LED indicator, remote control, temperature sensing
