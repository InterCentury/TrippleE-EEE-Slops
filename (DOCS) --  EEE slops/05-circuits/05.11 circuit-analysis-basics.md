# 05.11 - Circuit Analysis Basics

## 1. Topological Frameworks and Network Definitions

To perform systematic analysis on complex electrical networks, engineers must transition from component-level descriptions to topological network frameworks. A circuit can be mathematically modeled as a directed graph consisting of vertices (nodes) and edges (branches). Defining these geometric boundaries precisely is an absolute prerequisite for setting up accurate, solvable linear equations.

```text
> CIRCUIT TOPOLOGICAL BOUNDARY SCHEMA

       Node Alpha (A)                                    Node Beta (B)
  ┌──────────────────┬─────────────────────────────────┬──────────────────┐
  │                  │                                 │                  │
  ▼                  ▼                                 ▼                  ▼
┌───┐              ┌───┐                             ┌───┐              ┌───┐
│V1 │ [Branch 1]   │R1 │ [Branch 2]                  │R2 │ [Branch 3]   │R3 │ [Branch 4]
└───┘              └───┘                             └───┘              └───┘
  │                  │                                 │                  │
  ▼                  ▼                                 ▼                  ▼
  └──────────────────┴─────────────────────────────────┴──────────────────┘
                               Node Gamma (C)

```

### 1.1 Node

A node is defined as a point or junction where two or more circuit elements (such as resistors, capacitors, or voltage sources) make a direct electrical connection.

* **Essential Node:** A node that connects three or more separate circuit elements. Essential nodes serve as the primary anchoring vertices used in Nodal Analysis.

### 1.2 Branch

A branch represents a single, continuous path containing a single circuit element that connects one node to another. In graph theory, a branch corresponds directly to a network edge. The total number of branches ($b$) in a system represents the total number of unknown currents that must be solved.

### 1.3 Loop

A loop is any closed path formed by a sequence of branches within a circuit. To qualify as a valid loop, the path must start and end at the exact same node without passing through any intermediate node or branch more than once.

### 1.4 Mesh

A mesh is a specific type of loop that forms a single window or open space within the circuit diagram. A mesh cannot contain any other loops inside its boundary. Meshes serve as the fundamental independent loops required to execute Mesh Analysis.

## 3. Systematic Analytical Method A: Nodal Analysis

Nodal Analysis is a powerful technique that uses node voltages as the primary unknown variables to solve a circuit. This method relies fundamentally on **Kirchhoff's Current Law (KCL)**, which states that the net current entering an essential node must equal zero.

```text
> NODAL ANALYSIS LINEAR MATRIX SETTING

       Active Node Reference (V1)                  Active Node Reference (V2)
  ┌──────────────────┬─────────────────────────────────┬──────────────────┐
  │                  │                                 │                  │
  ▼                  ▼ I_12 (Inter-node current)       ▼                  ▼
┌────┐             ┌───┐                             ┌───┐              ┌────┐
│Is1 │ (Source 1)  │R1 │                             │R2 │              │Is2 │ (Source 2)
└────┘             └───┘                             └───┘              └────┘
  │                  │                                 │                  │
  ▼                  ▼                                 ▼                  ▼
  └──────────────────┴─────────────────────────────────┴──────────────────┘
                                 System Ground Reference (0V)

```

### 3.1 Step-by-Step Execution Protocol

1. **Identify Essential Nodes:** Locate all junctions where three or more branches intersect. Let the total count equal $n$.
2. **Select the Reference Ground:** Designate one essential node as the system common ground reference point, assigning it an absolute potential of zero volts ($0\text{V}$). This node is typically chosen based on having the highest concentration of branch connections.
3. **Assign Node Voltages:** Label the remaining $n-1$ non-reference essential nodes with unknown voltage variables ($V_1, V_2, \dots, V_{n-1}$). All branch voltages will be calculated relative to these variables.
4. **Apply KCL to Every Non-Reference Node:** Write a KCL equation for each node by expressing every leaving branch current in terms of the node voltages using Ohm's Law:

$$I = \frac{V_{\text{node}} - V_{\text{adjacent}}}{R_{\text{branch}}}$$


5. **Solve the Linear Equation Set:** Organize the equations into a linear system ($[\mathbf{G}][\mathbf{V}] = [\mathbf{I}]$) and solve for the unknown node voltages using matrix inversion or Gaussian elimination.

### 3.2 Setting Up the Linear Equations

For a system with two unknown nodes ($V_1$ and $V_2$) bounded by a reference ground, the KCL equilibrium statement at Node 1 is expressed as:

$$\frac{V_1 - 0}{R_{\text{ground1}}} + \frac{V_1 - V_2}{R_{12}} - I_{\text{source1}} = 0$$

Grouping terms by their respective node voltage variables highlights the clean matrix layout:

$$V_1 \left( \frac{1}{R_{\text{ground1}}} + \frac{1}{R_{12}} \right) - V_2 \left( \frac{1}{R_{12}} \right) = I_{\text{source1}}$$

## 4. Systematic Analytical Method B: Mesh Analysis

Mesh Analysis is a complementary technique that uses closed loop currents, rather than node voltages, as the primary unknown variables. This method relies fundamentally on **Kirchhoff's Voltage Law (KVL)**, which states that the algebraic sum of all voltage drops around any closed loop must equal zero.

```text
> MESH CURRENT INTERACTION MATRIX

  ┌───────────────────────────────┬───────────────────────────────┐
  │                               │                               │
  │     Mesh Loop Current I_A     │     Mesh Loop Current I_B     │
  │          ┌───────┐            │          ┌───────┐            │
  │          │   ↻   │            │          │   ↻   │            │
  │          └───────┘            │          └───────┘            │
  │                               │                               │
  │                 Shared Internal Branch Element                │
  │                 Current = I_A - I_B                           │
  └───────────────────────────────┴───────────────────────────────┘

```

### 4.1 Step-by-Step Execution Protocol

1. **Identify the Mesh Windows:** Count the total number of independent open window blocks ($m$) in the circuit schematic.
2. **Assign Mesh Currents:** Draw an clockwise imaginary loop current variable ($I_A, I_B, \dots, I_m$) inside each mesh window.
3. **Account for Shared Elements:** For components that lie on the boundary between two adjacent meshes, the true physical current through that element is the algebraic difference between the two competing mesh currents:

$$I_{\text{physical}} = I_{\text{active}} - I_{\text{opposing}}$$


4. **Apply KVL Around Every Mesh Window:** Travel clockwise around each loop perimeter, summing the voltage drops across each resistor ($V = I \cdot R$) and matching source potentials according to their entry polarity.
5. **Solve the Linear Equation Set:** Arrange the equations into a linear system ($[\mathbf{R}][\mathbf{I}] = [\mathbf{V}]$) and solve for the unknown mesh currents.

### 4.2 Setting Up the Linear Equations

For an independent mesh window (Mesh A) sharing a resistor element ($R_{\text{shared}}$) with an adjacent loop (Mesh B), the KVL equilibrium equation is written as:

$$-V_{\text{source}} + I_A(R_{\text{isolated}}) + (I_A - I_B)R_{\text{shared}} = 0$$

Grouping terms by their respective mesh current variables yields the standard matrix layout:

$$I_A(R_{\text{isolated}} + R_{\text{shared}}) - I_B(R_{\text{shared}}) = V_{\text{source}}$$

## 5. Circuit Superposition: Handling Complex Multi-Source Systems

The **Superposition Theorem** provides a powerful conceptual approach for analyzing linear circuits that contain multiple independent power sources. The theorem states that the total voltage drop across, or total current through, any component in a linear circuit is equal to the algebraic sum of the individual voltages or currents produced by each independent source acting alone.

```text
> POWER SOURCE TRANSITION CONTROL MODES

Source Class        │ Deactivation State Protocol           │ Replacement Impedance Boundary
────────────────────│───────────────────────────────────────│────────────────────────────────────────────────────────────
Voltage Source (V)  │ Set potential difference to 0V.       │ Replace completely with a solid short circuit wire track.
────────────────────│───────────────────────────────────────│────────────────────────────────────────────────────────────
Current Source (I)  │ Set current output to 0A.             │ Cut line completely; replace with an open circuit air gap.
────────────────────│───────────────────────────────────────│────────────────────────────────────────────────────────────

```

### 5.1 Step-by-Step Deactivation Protocol

To isolate the effects of a single independent source, all other independent sources must be systematically deactivated or "turned off":

* **Deactivating an Independent Voltage Source:** Setting its output to zero volts ($0\text{V}$) means forcing a zero-voltage drop across its terminals. The source is therefore replaced with a direct, continuous short-circuit wire path.
* **Deactivating an Independent Current Source:** Setting its output to zero Amperes ($0\text{A}$) means forcing zero current through its branch. The source is therefore replaced with an open-circuit air gap.

### 5.2 Crucial Constraints: Dependent Sources and Power Calibrations

1. **Never Deactivate Dependent Sources:** Controlled or dependent sources (such as voltage-controlled current sources) represent active structural feedback loops within the circuit. They must remain active and unaltered throughout the entire analysis.
2. **Power Calculations are Non-Linear:** The superposition theorem applies strictly to linear circuit variables like voltage and current. It cannot be applied directly to calculate total power consumption ($P = I^2R = \frac{V^2}{R}$). Because power scales quadratically, calculating total power requires finding the total combined voltage or current first, and then applying the power formula to that final value.

## 7. Summary Summary Checklist

1. **Topological Graph Mapping:** Advanced circuit analysis treats networks as mathematical graphs, mapping intersections as nodes and components as branches.
2. **Essential Node Identification:** Essential nodes are junctions where three or more paths meet, forming the primary connection points for Nodal Analysis equations.
3. **Mesh Window Boundaries:** A mesh is an independent loop that contains no other loops, defining the geometric boundary lines used in Mesh Analysis equations.
4. **KCL-Driven Nodal Systems:** Nodal Analysis uses node voltages as its primary variables, applying KCL to sum the branch currents leaving each junction node.
5. **KVL-Driven Mesh Networks:** Mesh Analysis uses clockwise loop currents as its variables, applying KVL to sum the voltage drops around each independent mesh path.
6. **Shared Component Interactions:** When a component is shared between two adjacent meshes, its physical current is the difference between the two competing loop currents.
7. **Linear Superposition Scaling:** The Superposition Theorem splits multi-source linear networks into separate, single-source sub-circuits for easier calculation.
8. **Voltage Deactivation Shorting:** Independent voltage sources are turned off by replacing them with short circuits to force a zero-volt potential drop.
9. **Current Deactivation Opening:** Independent current sources are turned off by replacing them with open circuit air gaps to force a zero-Ampere line current.
10. **Non-Linear Power Limits:** Superposition can only be applied to linear variables like voltage and current; it cannot be used for non-linear power metrics ($I^2R$).
