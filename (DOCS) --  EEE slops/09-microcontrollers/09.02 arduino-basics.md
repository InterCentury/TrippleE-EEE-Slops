# 09.02 - Arduino Basics

## What is Arduino?

Arduino is an open-source electronics platform based on easy-to-use hardware and software. It consists of a programmable microcontroller board and an integrated development environment (IDE) that allows you to write, compile, and upload code to the board.

Arduino was created in 2005 at the Interaction Design Institute Ivrea in Italy by Massimo Banzi, David Cuartielles, Tom Igoe, Gianluca Martino, and David Mellis. The goal was to provide an affordable and simple way for students and non-engineers to create interactive projects. Today, Arduino is the most popular platform for electronics prototyping, education, and DIY projects worldwide.

## Pulse Width Modulation (PWM)

### PWM Explanation

```
PWM PRINCIPLE

    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │   PWM simulates analog output by switching pin ON/OFF very fast             │
    │   Duty cycle determines average voltage                                     │
    │                                                                             │
    │   0% Duty (always OFF)       25% Duty        50% Duty        75% Duty       │
    │   ┌─────────────────┐        ┌───┬─────────┐  ┌───┬───┬───┐  ┌───┬───┐      │
    │   │                 │        │   │         │  │   │   │   │  │   │   │      │
    │   │    LOW (0V)     │        │ON │  OFF    │  │ON │OFF│ON │  │ON │OFF│      │
    │   │                 │        │   │         │  │   │   │   │  │   │   │      │
    │   └─────────────────┘        └───┴─────────┘  └───┴───┴───┘  └───┴───┘      │
    │   ────────────────►          ────────►        ────────►      ────────►      │
    │   Average: 0V                Average: 1.25V  Average: 2.5V  Average: 3.75V  │
    │                                                                             │
    └─────────────────────────────────────────────────────────────────────────────┘


    PWM FORMULAS:

    Duty Cycle (%) = (PWM_Value / 255) × 100%
    Average Voltage (V) = (PWM_Value / 255) × Vcc

    WHERE:
    PWM_Value = 0 to 255
    Vcc = 5V for Arduino


    EXAMPLE:

    PWM_Value = 128
    Duty Cycle = (128 / 255) × 100% = 50.2%
    Average Voltage = (128 / 255) × 5V = 2.51V


    LED BRIGHTNESS FORMULA (Non-linear perception):

    Human eye perceives brightness logarithmically
    For smooth fading: PWM = 255 × ( (brightness%)² / 10000 )

    Example for 50% perceived brightness:
    PWM = 255 × (2500 / 10000) = 255 × 0.25 = 64 (not 128!)
```

    const int ledPin = 13;

      pinMode(ledPin, OUTPUT);
      pinMode(buttonPin, INPUT_PULLUP);  // Enable internal pull-up
    }

    void loop() {
      buttonState = digitalRead(buttonPin);

      if (buttonState == LOW) {          // Button pressed (LOW with pull-up)
        digitalWrite(ledPin, HIGH);
      } else {
        digitalWrite(ledPin, LOW);
      }
    }

    │                                                                             │

    │                                                                             │

      pinMode(ledPin, OUTPUT);
      Serial.begin(9600);
    }

    void loop() {
      potValue = analogRead(potPin);           // Read 0-1023
      brightness = map(potValue, 0, 1023, 0, 255);  // Scale to 0-255
      analogWrite(ledPin, brightness);          // Set LED brightness

      Serial.print(potValue);
      Serial.print("  Brightness: ");

```
ULTRASONIC SENSOR CIRCUIT

    ┌─────────────────────────────────────────────────────────────────────────────┐
    │                                                                             │
    │   ARDUINO UNO                    HC-SR04 ULTRASONIC                         │
    │                                                                             │
    │   5V ────────────────────────────────────────────── VCC                     │
    │                                                                             │
    │   GND ───────────────────────────────────────────── GND                     │
    │                                                                             │
    │   Pin 9 ────────────────────────────────────────── TRIG                     │
    │                                                                             │

    │                                                                             │
    │                                                                             │
    │   DISTANCE FORMULA:                                                         │
    │                                                                             │
    │   Distance (cm) = (Travel Time (µs) × Sound Speed (343 m/s)) / 2            │
    │                                                                             │
    │   Simplified: Distance (cm) = Travel Time (µs) / 58                         │

    const int trigPin = 9;
    const int echoPin = 10;
    long duration;
    float distanceCm;
    float distanceIn;

    void setup() {
      pinMode(trigPin, OUTPUT);
      pinMode(echoPin, INPUT);
      Serial.begin(9600);
    }

    void loop() {
      // Send 10µs trigger pulse
      digitalWrite(trigPin, LOW);
      delayMicroseconds(2);
      digitalWrite(trigPin, HIGH);
      delayMicroseconds(10);
      digitalWrite(trigPin, LOW);

      // Measure echo pulse duration
      duration = pulseIn(echoPin, HIGH);

      // Calculate distance
      distanceCm = duration / 58.0;
      distanceIn = duration / 148.0;

      Serial.print("Distance: ");
      Serial.print(distanceCm);
      Serial.print(" cm  (");
      Serial.print(distanceIn);
      Serial.println(" inches)");

      delay(500);
    }
```

### Power Supply Options

```
POWERING ARDUINO

    Method 1: USB Cable (5V)
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │   USB Port ──► Computer or USB charger                                     │
    │   Voltage: 5V                                                              │
    │   Max Current: 500mA (USB 2.0), 900mA (USB 3.0)                           │
    │   Best for: Programming, low-power projects                               │
    └─────────────────────────────────────────────────────────────────────────────┘

    Method 2: DC Jack (7-12V)
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │   DC Jack ──► Wall adapter or battery (center positive)                   │
    │   Voltage: 7-12V (recommended), 6-20V (absolute)                          │
    │   Max Current: Limited by regulator (500mA at 5V)                         │
    │   Best for: Standalone projects, powering multiple components            │
    └─────────────────────────────────────────────────────────────────────────────┘

    Method 3: Vin Pin (7-12V)
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │   Vin Pin ──► External DC source (same as DC jack)                        │
    │   Bypasses reverse polarity protection                                    │
    │   Caution: No reverse polarity protection!                                │
    └─────────────────────────────────────────────────────────────────────────────┘

    Method 4: 5V Pin (5V regulated)
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │   5V Pin ──► External regulated 5V (bypasses onboard regulator)          │
    │   Max Current: Depends on external supply                                │
    │   Caution: Bypasses reverse polarity and overvoltage protection!         │
    └─────────────────────────────────────────────────────────────────────────────┘


    POWER CONSUMPTION CALCULATION:

    Total Current = Arduino base (50mA) + Σ(I_loads)

    Example:
    Arduino: 50mA
    3 LEDs (20mA each): 60mA
    HC-SR04 sensor: 15mA
    Servo motor: 200mA
    Total: 325mA

    For DC jack (7-12V input to 5V regulator):
    Power dissipated in regulator = (V_in - 5) × I_total
    = (9 - 5) × 0.325 = 4 × 0.325 = 1.3W (warm but safe)
```

### Low Power Techniques

```
POWER SAVING FORMULAS

    Sleep Mode Currents (ATmega328P):

    Mode                    Current        Wake-up Sources
    ──────────────────────────────────────────────────────────────────────────────
    Active (16MHz)          15-20mA        - (normal operation)
    Idle                    4-6mA          Any interrupt
    ADC Noise Reduction     1-2mA          ADC, Timer, I2C
    Power-down              0.1-10µA       External interrupt, pin change
    Power-save              1-2µA          Timer, external interrupt


    BATTERY LIFE CALCULATION:

    Battery Life (hours) = Battery Capacity (mAh) / Average Current (mA)

    Example: 2000mAh battery, average 50mA draw
    Life = 2000 / 50 = 40 hours

    With power-down mode (10µA) + wake every 10 seconds for 100ms (20mA)
    Average = (20mA × 0.1s + 0.01mA × 9.9s) / 10s = (2 + 0.099) / 10 = 0.21mA
    Life = 2000 / 0.21 = 9523 hours (~400 days!)
```

```
COMMON PROBLEMS AND SOLUTIONS

    Problem                     Possible Solution
    ──────────────────────────────────────────────────────────────────────────────
    Board not detected          Check USB cable, drivers, port selection
    
    Upload fails                Check board type, port, no other program using port

    doesn't work
    
    Pins not responding         Check pinMode setting, no voltage applied to output
    
    Serial gibberish            Check baud rate matches Serial.begin()
    
    Program runs slowly         Check delays, loops, avoid blocking code
    
    Board resets randomly       Check power supply (low voltage), add capacitor
    
    Unexpected readings         Check floating inputs (use pull-up/pull-down)

    Analog readings noisy       Add capacitor between AREF and GND, use averaging

## Arduino Formulas Quick Reference

```
FORMULAS SUMMARY

    LED Resistor:           R = (V_supply - V_LED) / I_LED
    
    Voltage Divider:        V_out = V_in × (R2 / (R1 + R2))
    
    ADC Conversion:         Value = (Voltage × 1023) / 5.0
                            Voltage = (Value × 5.0) / 1023
    
    PWM Duty Cycle:         Duty% = (PWM_Value / 255) × 100%
                            Avg Voltage = (PWM_Value / 255) × Vcc

                            inches = duration / 148

    Serial Baud Rate:       Data rate ≈ Baud × 0.8

## Summary

1. **Arduino** is an open-source electronics platform for prototyping and education

2. **ATmega328P** is the main microcontroller (8-bit, 16MHz, 32KB Flash, 2KB SRAM)

3. **14 Digital I/O pins** (0-13), 6 with PWM (~ symbol)

4. **6 Analog Input pins** (A0-A5), 10-bit ADC (0-1023)

5. **Power options:** USB (5V, 500mA), DC jack (7-12V), Vin pin, 5V pin

6. **PWM** simulates analog output using duty cycle (0-255, 490Hz)

7. **I/O voltage:** 0V (LOW), 5V (HIGH), input threshold 2.0V

8. **Maximum current:** 20mA recommended per pin, 40mA absolute max

9. **Serial communication** uses pins 0 (RX) and 1 (TX), avoid during upload

10. **I2C** uses A4 (SDA) and A5 (SCL), requires 4.7kΩ pull-up resistors

11. **SPI** uses pins 10 (SS), 11 (MOSI), 12 (MISO), 13 (SCK)

12. **AnalogRead()** returns 0-1023 for 0-5V, 10-bit resolution

13. **AnalogWrite()** uses PWM (0-255) on ~ pins

14. **delay(ms)** blocks execution; use millis() for non-blocking timing

15. **map()** scales values from one range to another

16. **constrain()** limits a value to a range

17. **digitalWrite()** speed ≈ 1-5µs; analogRead() ≈ 100µs

18. **Sleep modes** reduce power consumption to 0.1-10µA

19. **Flyback diode** required for inductive loads (motors, relays)

20. **Always verify pin connections** before applying power
