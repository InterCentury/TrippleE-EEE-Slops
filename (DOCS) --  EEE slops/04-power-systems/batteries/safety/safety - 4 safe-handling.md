# 04.21 - Safe Battery Handling

## What is Safe Battery Handling?

Safe battery handling encompasses the practices, procedures, and precautions necessary to prevent accidents, injuries, and property damage when working with batteries of all types. It includes proper storage, transportation, installation, usage, charging, and disposal techniques.

Batteries store significant amounts of energy in chemical form. Improper handling can release this energy suddenly and violently, causing burns, fires, explosions, chemical exposure, and electric shock. Understanding and following safe handling practices is essential for anyone who works with batteries, from hobbyists to professionals.

Ten rules that apply to all battery types.

## Battery Inspection

### Pre-Use Inspection

Always inspect batteries before handling or using them.

```
VISUAL INSPECTION CHECKLIST

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   ☐ TERMINALS - Clean, not corroded, not bent               │
    │                                                             │
    │   ☐ CASE - No cracks, swelling, or deformation              │
    │                                                             │
    │   ☐ LEAKS - No white/green crust, liquid, or smell          │
    │                                                             │
    │   ☐ LABELS - Legible (so you know what it is)               │
    │                                                             │
    │   ☐ DENTS - No dents or crushed areas (Li-ion)              │
    │                                                             │
    │   ☐ PUFFING - Li-ion only – if swollen, DO NOT USE!         │
    │                                                             │
    │   ☐ WRAPPER - Intact, no tears (Li-ion, NiMH)               │
    │                                                             │
    │   ☐ MANUFACTURER - Reputable brand (avoid no-name)          │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘


    WHAT TO DO IF DAMAGE IS FOUND:

    Damage Type                 Action
    ──────────────────────────────────────────────────────────────
    Slight corrosion            Clean with baking soda/water, test
    Severe corrosion            Do not use – recycle
    Cracked case                Do not use – recycle (dangerous!)
    Swollen Li-ion              Do NOT use – immediate hazardous waste
    Leaking                     Do not handle without gloves – recycle
    Bent terminals              Carefully straighten (if safe) or recycle
    No-name brand               Use with caution – monitor closely


    INSPECTION FREQUENCY:

    Usage                       Inspection Frequency
    ──────────────────────────────────────────────────────────────
    Daily use                   Before each use
    Weekly use                  Once per week
    Monthly use                 Before each use
    Storage (active use)        Every 3 months
    Storage (emergency backup)  Every 6 months
    Automotive (under hood)     Every oil change
```

### Testing Before Use

Electrical testing to ensure battery is safe.

```
SAFETY TESTS

    VOLTAGE TEST (All batteries):

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Chemistry    Normal V    Low (replace)   Overcharged      │
    │   ──────────────────────────────────────────────────────────│
    │   Alkaline     1.55-1.65V   <1.3V          1.7V+ (rare)     │
    │   NiMH         1.35-1.45V   <1.2V          1.5V+ (bad)      │
    │   Lead-acid    12.6-12.8V   <12.0V          >14.4V (danger) │
    │   Li-ion (4.2V) 4.15-4.20V <3.0V           >4.25V (danger)  │
    │   LiFePO₄      3.35-3.40V  <2.8V           >3.65V (danger)  │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘

    If voltage is outside normal range:
    ├── Low voltage: May be ok, but capacity reduced
    ├── Very low voltage: Do not charge (Li-ion – danger!)
    └── Overcharged: Do not use – immediate hazardous waste


    CONTINUITY TEST (Short circuit check):

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Measure resistance across terminals (battery disconnected)│
    │                                                             │
    │   Normal: Infinite (OL) – No short                          │
    │   Short: 0Ω – DO NOT USE – internal short (explosion risk)  │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘


    INTERNAL RESISTANCE TEST (Advanced):

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Measure voltage under light load, then heavier load       │
    │   R_internal = (V_no_load - V_load) / I_load                │
    │                                                             │
    │   High internal resistance = damaged battery (replace)      │
    │   Very high internal resistance = unsafe (dispose)          │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

## Safe Installation

### Inserting Batteries

Proper technique for installing batteries.

```
CORRECT INSTALLATION PROCEDURE

    STEP 1: Verify Battery Type
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Check device label for required battery type              │
    │   Use EXACT type – no substitutes!                          │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘


    STEP 2: Check Polarity
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Look for + and - markings in device                       │
    │   Match battery terminals to device markings                │
    │                                                             │
    │   Device:              Battery:                             │
    │   ┌─────┐              ┌─────┐                              │
    │   │  +  │              │  +  │                              │
    │   │  -  │              │  -  │                              │
    │   └─────┘              └─────┘                              │
    │                                                             │
    │ !!! Incorrect polarity can damage device and cause          │
    │     battery leakage, fire, or explosion!                    │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘


    STEP 3: Clean Terminals
    ┌──────────────────────────────────────────────────────────────┐
    │                                                              │
    │   If corroded:                                               │
    │   ├── Alkaline leakage: Clean with vinegar (acid neutralizes)│
    │   ├── Lead-acid: Clean with baking soda (base neutralizes)   │
    │   ├── NiMH: Clean with isopropyl alcohol                     │
    │   └── Dry thoroughly before inserting battery                │
    │                                                              │
    └──────────────────────────────────────────────────────────────┘


    STEP 4: Insert Correctly
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   DO:                        DON'T:                         │
    │   ├── Insert straight        ├── Force backwards            │
    │   ├── Match polarity         ├── Mix old and new            │
    │   ├── Use correct size       ├── Mix chemistries            │
    │   └── Close securely         └── Leave compartment open     │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘


    STEP 5: Test Device
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Power on device briefly to verify correct operation       │
    │   If device doesn't work:                                   │
    │   ├── Remove batteries immediately                          │
    │   ├── Double-check polarity                                 │
    │   ├── Check for damage                                      │
    │   └── Test batteries individually                           │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

### Multi-Battery Devices

Special considerations for devices using multiple batteries.

```
MULTI-BATTERY RULES

    DO:
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   ✓ Use same brand batteries all positions                  │
    │   ✓ Use same chemistry (all alkaline, all NiMH, etc.)       │
    │   ✓ Use same age (all new, or all used equally)             │
    │   ✓ Use same charge level (for rechargeable)                │
    │   ✓ Replace ALL batteries at same time                      │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘


    DON'T:
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   X Mix alkaline with NiMH (different voltages)             │
    │   X Mix old and new batteries (old may leak/overheat)       │
    │   X Mix different brands (different characteristics)        │
    │   X Mix charged and discharged rechargeables                │
    │   X Leave one dead battery in device (reverse charging)     │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘


    WHY IT MATTERS:

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Problem: Mixing old and new alkaline batteries            │
    │                                                             │
    │   New battery: 1.6V, low internal resistance                │
    │   Old battery: 1.2V, high internal resistance               │
    │                                                             │
    │   Result:                                                   │
    │   ├── Old battery gets reverse charged                      │
    │   ├── Old battery heats up                                  │
    │   ├── Old battery leaks (damages device)                    │
    │   └── Alkaline batteries can explode under reverse charge!  │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

## Summary

1. **Safe handling** prevents accidents, injuries, and property damage

2. **10 golden rules:** Read labels, use correct battery, check polarity, inspect, cover terminals, store properly, don't mix batteries, use proper charger, don't damage, dispose properly

3. **Inspect before use:** Check terminals, case, leaks, swelling (Li-ion), wrapper, manufacturer

4. **Voltage limits:** Li-ion >4.25V = danger, >4.5V = explosion imminent; Lead-acid >14.4V = gassing risk

5. **Never mix batteries:** Different chemistry, age, brand, or charge level (causes leakage, explosion)

6. **Safe installation:** Match polarity, clean terminals, insert straight, test briefly

7. **Charging environment:** Concrete, ceramic, metal, LiPo bag (NOT carpet, wood, near flammables)

8. **Never leave Li-ion charging unattended** – check every 10 minutes for heat, swelling, hissing

9. **Lead-acid MUST charge in ventilated area** – hydrogen gas explosion risk

10. **Do not recharge alkaline batteries** – they leak or explode

11. **Storage:** Li-ion at 50% charge (3.7V), cool place; Lead-acid fully charged, recharge every 3-6 months

12. **9V batteries extremely dangerous loose** – terminals contact keys/coins → short circuit → fire/explosion

13. **Air travel:** Li-ion MUST be carry-on, ≤100Wh no approval, 101-160Wh airline approval needed

14. **Leak response:** Gloves + goggles, neutralize alkaline (vinegar), lead-acid (baking soda), Li-ion (absorb only)

15. **Fire response:** EVACUATE, call 911, Class D or sand for Li-ion, Class B/C for lead-acid

16. **Disposal:** Never in trash (except modern alkaline – check local rules), recycle at Call2Recycle, Best Buy, Home Depot
