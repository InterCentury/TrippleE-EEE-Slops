# 04. Power Supply (AC-DC Converter)

## What is a Power Supply?

A power supply is an electronic device that converts electrical power from one form to another, typically converting alternating current (AC) from a wall outlet to regulated direct current (DC) for electronic devices. Unlike a simple adapter, power supplies often include sophisticated regulation, multiple outputs, and protection features.

Power supplies are the heart of virtually every electronic device. They exist as wall adapters (external), internal units inside computers and TVs, and as bench power supplies for testing and development. Understanding power supplies is essential for anyone working with electronics.

## Types of Power Supplies

### Linear Power Supply

The traditional design, using a mains-frequency transformer.

```
LINEAR POWER SUPPLY BLOCK DIAGRAM

    ┌───────────────────────────────────────────────────────────────────────────────┐
    │                                                                               │
    │   AC Input ──► Transformer ──► Rectifier ──► Filter ──► Regulator ──► DC Out  │          
    │   (120/230V)    (step down)      (diodes)      (cap)        (linear IC)       │  
    │                                                                               │
    │        │              │              │            │            │              │           
    │        ▼              ▼              ▼            ▼            ▼              │            
    │    120V AC        12V AC         Pulsing      Rippled       Regulated         │             
    │                   (60Hz)         DC (120Hz)   DC (120Hz)    DC (smooth)       │            
    │                                                                               │                   
    └───────────────────────────────────────────────────────────────────────────────┘


    WAVEFORM PROGRESSION:

    ┌──────────────────────────────────────────────────────────────┐
    │                                                              │
    │   Transformer      Rectifier        Filter         Regulator │
    │   Output           Output           Output          Output   │
    │                                                              │
    │   ╱╲    ╱╲          ╱╲╱╲╱╲           ───────_          ────  │
    │  ╱  ╲  ╱  ╲        ╱    ╱             │    │             │   │
    │ ╱    ╲╱    ╲      ╱    ╱              │    │             │   │
    │                    (full-wave)      small ripple       flat  │
    │                                                              │
    └──────────────────────────────────────────────────────────────┘

    CHARACTERISTICS:
    ├── Heavy (due to iron core transformer)
    ├── Large size
    ├── Inefficient (40-60%)
    ├── Generates significant heat
    ├── Very low output noise (<1mV ripple)
    ├── Excellent regulation
    ├── Fast transient response
    ├── Simple design, easy to repair
    ├── No electromagnetic interference (EMI)
    ├── Low cost for low power (<10W)
    └── Becoming rare (replaced by switching supplies)

    ADVANTAGES:
    ├── Very clean output (low noise) – ideal for audio, RF, precision
    ├── Simple circuit (easy to troubleshoot)
    ├── Reliable (fewer components)
    ├── No high-frequency switching noise
    └── No EMI filtering required

    DISADVANTAGES:
    ├── Heavy and bulky
    ├── Inefficient (wastes power as heat)
    ├── Fixed input voltage (120V or 230V only)
    ├── Only step-down (cannot step up)
    └── Large heat sinks required
```

### Switching Power Supply (SMPS)

The modern standard, using high-frequency switching.

```
SWITCHING POWER SUPPLY BLOCK DIAGRAM

    ┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
    │                                                                                                 │
    │   AC Input ──► Rectify ──► Filter ──► Switch ──► Transformer ──► Rectify ──► Filter ──► DC Out  │                                       
    │               (diodes)    (cap)      (MOSFET)  (high freq)    (diodes)    (cap)                 │                       
    │                                                                                                 │                                                               
    │        │          │          │           │            │           │           │                 │                       
    │        ▼          ▼          ▼           ▼            ▼           ▼           ▼                 │                       
    │    120V AC    170V DC    170V DC     50kHz AC     50kHz AC     Pulsing    Regulated             │                           
    │              (pulsing)   (smooth)    (high V)     (low V)      DC          DC                   │                     
    │                                                                                                 │                                                               
    │                                    ┌────────────────┐                                           │                                     
    │                                    │  Feedback      │                                           │                                     
    │                                    │  (optocoupler) │                                           │
    │                                    └────────────────┘                                           │
    │                                                                                                 │                       
    └─────────────────────────────────────────────────────────────────────────────────────────────────┘


    WHY HIGH FREQUENCY:

    ┌───────────────────────────────────────────────────────────────┐
    │                                                               │
    │   Transformer size is INVERSELY proportional to frequency     │
    │                                                               │
    │   60 Hz transformer:   large, heavy (iron core, kg scale)     │
    │   50 kHz transformer:  tiny, light (ferrite core, gram scale) │
    │   1 MHz transformer:   extremely tiny (surface mount)         │
    │                                                               │
    │   Higher frequency = smaller transformer = smaller PSU!       │
    │                                                               │
    └───────────────────────────────────────────────────────────────┘

    CHARACTERISTICS:
    ├── Lightweight (small high-frequency transformer)
    ├── Compact size
    ├── Efficient (70-90% typical, 90-95% premium)
    ├── Cool operation (less wasted heat)
    ├── Higher output noise (10-100mV ripple)
    ├── Good regulation (3-5% typical)
    ├── Slower transient response than linear
    ├── Complex design (harder to repair)
    ├── Generates EMI (requires filtering)
    ├── Wide input range (90-264V AC, universal)
    ├── Can step up or down voltage
    └── Dominates modern market

    ADVANTAGES:
    ├── Small and lightweight
    ├── Efficient (less heat, lower electricity bill)
    ├── Universal input (works anywhere)
    ├── Can step up voltage (boost topology)
    ├── Multiple outputs easily
    └── Lower cost at high power (>50W)

    DISADVANTAGES:
    ├── Noisy output (ripple and switching spikes)
    ├── Complex circuit (harder to repair)
    ├── Generates EMI (can interfere with radios)
    ├── Slower transient response
    └── Audible noise possible (coil whine)
```

### Comparison: Linear vs Switching

```
LINEAR vs SWITCHING POWER SUPPLY

    Feature                 Linear PSU          Switching PSU (SMPS)
    ──────────────────────────────────────────────────────────────
    Efficiency              40-60%              70-95%
    Size                    Large               Small
    Weight                  Heavy               Light
    Heat output             High                Low
    Output noise (ripple)   <1 mV               10-100 mV
    Regulation              Excellent (0.1%)    Good (1-5%)
    Transient response      Very fast           Moderate (100-500µs)
    Input voltage range     Fixed (120/230V)    Wide (90-264V)
    Input frequency         50/60 Hz            50-60 Hz (rectified)
    Transformer frequency   50/60 Hz            50 kHz - 1 MHz
    Transformer core        Iron (heavy)        Ferrite (light)
    EMI/RFI                 Very low            Requires filtering
    Complexity              Simple              Complex
    Reliability             Excellent           Good
    Repairability           Easy                Difficult
    Cost (low power <30W)   Lower               Higher
    Cost (high power >100W) Much higher         Lower
    Audible noise           Possible (50/60 Hz) Possible (high-freq whine)
    Power factor            Poor (0.5-0.6)      Good (0.9-0.99 with PFC)
    Hold-up time            Short (1-2 cycles)  Long (10-20ms)
    Inrush current          Low                 High (requires NTC/PTC)


    SELECTION GUIDELINE:

    Use Linear PSU when:
    ├── You need very clean power (audio, RF, medical)
    ├── Power is low (<30W)
    ├── Efficiency and size don't matter
    ├── You need simple, repairable design
    └── Fixed input voltage is acceptable

    Use Switching PSU when:
    ├── Efficiency and size matter (most modern devices)
    ├── Power is high (>50W)
    ├── Universal input needed (international products)
    ├── Multiple outputs required
    └── Cost at high power is important
```

    Higher efficiency = less heat = smaller fan = quieter.

### Protection Features

```
PROTECTION CIRCUITS

    Protection              Symbol      Function
    ──────────────────────────────────────────────────────────────
    OCP (Over Current)      ⚡         Shuts down if current too high
    OVP (Over Voltage)      ⚡         Shuts down if voltage too high
    UVP (Under Voltage)     ⚡         Shuts down if voltage too low
    OTP (Over Temperature)  🌡️        Shuts down if too hot
    SCP (Short Circuit)     ⚡         Shuts down if output shorted
    OLP (Over Load)         ⚡         Shuts down if power too high


    TYPICAL TRIP POINTS:

    Protection              Typical Trip              Recovery
    ──────────────────────────────────────────────────────────────
    OCP                     110-150% of rated         Auto or latch
    OVP                     >120% of nominal          Latch (needs power cycle)
    UVP                     <80% of nominal           Auto
    OTP                     >85-100°C                 Auto (when cooled)
    SCP                     Instant (<1ms)            Auto or latch


    WHY PROTECTION MATTERS:

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Without protection:                                      │
    │   ├── Over-current can melt wires, cause fire              │
    │   ├── Over-voltage can destroy connected devices           │
    │   ├── Short circuit can cause sparks, fire, damage         │
    │   ├── Over-temperature can melt components, catch fire     │
    │                                                             │
    │   Quality power supplies have ALL protections              │
    │   Cheap power supplies may have few or none                │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

## Common Problems and Troubleshooting

### Problem 1: Power Supply Won't Turn On

```
SYMPTOMS:
├── No output voltage
├── No fan spin
├── No indicator lights
├── Completely dead

CAUSES:
├── No AC input (unplugged, tripped breaker, blown fuse)
├── Internal fuse blown (overload or surge)
├── Defective power switch
├── Failed input stage (rectifier, filter cap)
├── Blown MOSFET or switching IC
├── Thermal fuse tripped (needs cool-down)

DIAGNOSIS:
├── Verify AC outlet has power (test with lamp or meter)
├── Check AC cord continuity
├── Measure AC voltage at power supply input
├── Inspect for visible damage (bulging caps, burn marks)
├── Check internal fuse (if accessible)
├── Test with known good load (not device)

SOLUTIONS:
├── Check AC outlet breaker
├── Replace AC cord if damaged
├── Replace internal fuse (correct rating, slow-blow)
├── If fuse blows again: internal short (replace PSU)
├── Let cool if thermal protection tripped (30 minutes)
├── For failed components: replace PSU (not cost-effective to repair)
```

### Problem 2: Output Voltage Too Low

```
SYMPTOMS:
├── Device doesn't work or works poorly
├── Measured voltage below specification
├── Voltage drops under load

CAUSES:
├── Power supply overloaded (exceeds rated current)
├── Input voltage low (brownout)
├── Defective output capacitor (ESR high, dried out)
├── Poor regulation (cheap power supply)
├── Long or undersized output wires (voltage drop)
├── Loose connection (high resistance)

DIAGNOSIS:
├── Measure voltage at power supply output (no load)
├── Measure voltage at device (under load)
├── Compare to specification (should be within ±5%)
├── Measure current draw (clamp meter)
├── Check if current exceeds rating
├── Measure voltage drop across wires

SOLUTIONS:
├── Reduce load (add second power supply)
├── Use higher current power supply
├── Replace defective output capacitors
├── Use thicker/shorter output wires
├── Clean and tighten connections
├── For line voltage brownout: use UPS or wider-range PSU
```

### Problem 3: Excessive Ripple and Noise

```
SYMPTOMS:
├── Audio equipment hums or buzzes
├── Digital circuits behave erratically
├── Oscilloscope shows noisy DC
├── Analog sensor readings fluctuate

CAUSES:
├── Dried out output capacitors (high ESR)
├── Power supply overloaded (exceeds rating)
├── Switching supply normal operation (10-100mV ripple)
├── No output capacitor (or too small)
├── Ground loops in system
├── Poor power supply design (cheap unit)

DIAGNOSIS:
├── Measure AC voltage across DC output (multimeter AC mode)
├── Good: <10mV AC (linear), <50mV (good SMPS)
├── Poor: >50mV AC (linear), >100mV (SMPS)
├── Use oscilloscope (AC coupled) to see ripple waveform
├── Check output capacitors for bulging or leakage

SOLUTIONS:
├── Replace output capacitors (low ESR type)
├── Add additional output capacitor (1000-4700µF)
├── Reduce load (stay within rating)
├── For sensitive loads: use linear power supply
├── Add LC filter on output (inductor + capacitor)
├── Check grounding (single point ground)
├── Replace with higher quality power supply
```

### Problem 4: Overheating / Fan Issues

```
SYMPTOMS:
├── Power supply too hot to touch
├── Fan not spinning or spinning slowly
├── Thermal shutdown (PSU turns off, then back on)
├── Burning smell

CAUSES:
├── Overloaded (exceeds rated power)
├── Fan failed (seized, bearing worn)
├── Dust accumulation (blocks airflow)
├── High ambient temperature
├── Poor ventilation (blocked vents)
├── Inefficient power supply (linear, cheap SMPS)

DIAGNOSIS:
├── Measure load power (should be ≤ rating)
├── Check fan operation (should spin at power-on)
├── Listen for unusual fan noise (grinding, clicking)
├── Inspect for dust buildup (especially intake vents)
├── Feel exhaust air temperature (should be warm, not hot)

SOLUTIONS:
├── Reduce load (stay within 80% of rating)
├── Replace fan (if accessible)
├── Clean dust with compressed air
├── Improve ventilation (more space around PSU)
├── Add external fan for cooling
├── Replace with higher efficiency power supply (less heat)
├── Replace if fan failure caused overheating damage

WARNING: Power supplies contain LETHAL voltages even after disconnect!
Large capacitors can hold charge for hours.
Wait 5+ minutes before opening any power supply.
```

## Summary

1. **Power supply** converts AC to regulated DC for electronic devices

2. **Linear PSU:** heavy, inefficient (40-60%), very low noise, simple, reliable

3. **Switching PSU (SMPS):** light, efficient (70-95%), some noise, complex, universal input

4. **Higher switching frequency = smaller transformer = smaller PSU**

5. **Transformer size ∝ 1/frequency** (60Hz iron core heavy, 50kHz ferrite core light)

6. **80 PLUS certification:** Bronze (82-85%), Silver (85-88%), Gold (87-90%), Platinum (90-92%), Titanium (90-94%)

7. **Peak efficiency at 40-60% load** – size PSU appropriately

8. **Ripple and noise:** Linear (<1mV), good SMPS (10-30mV), budget SMPS (50-100mV)

9. **ATX power supply** provides +12V, +5V, +3.3V, -12V, +5VSB with Power Good signal

10. **Bench power supply** has adjustable voltage and current limit, CV/CC modes

11. **DIN rail PSU** for industrial control panels (24V common)

12. **LED driver** is constant current (not constant voltage) for LEDs

13. **Protections:** OCP, OVP, UVP, OTP, SCP – quality PSUs have all

14. **Efficiency loss** becomes heat – 500W load at 90% = 56W heat

15. **ATX Power Good (PG)** signal – motherboard waits for PG (100-500ms) before boot

16. **No-load power consumption** (vampire power) – unplug when not in use

17. **Safety certifications:** UL (US), CE (Europe), TUV (Germany) – avoid uncertified

18. **Red flags:** too hot, burning smell, smoke, bulging capacitors – unplug immediately

19. **Hold-up time** – switching PSU can ride through brief power loss (10-20ms)

20. **Always discharge capacitors** before working inside – lethal voltages remain!
