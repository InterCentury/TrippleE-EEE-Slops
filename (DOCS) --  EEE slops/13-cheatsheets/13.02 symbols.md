# 13.02 - Common Electrical and Electronics Symbols

## 1. Basic Electrical Quantities
```
1.  V: Voltage — electrical potential difference between two points.
2.  I: Current — flow of electric charge.
3.  R: Resistance — opposition to current flow.
4.  P: Power — rate of electrical energy transfer.
5.  E: Energy — total electrical work or stored energy.
6.  Q: Charge — amount of electric charge.
7.  f: Frequency — number of cycles per second.
8.  T: Period — time for one complete cycle.
9.  η: Efficiency — ratio of useful output power to input power.
10. τ: Time constant — speed of charging/discharging or current rise/fall.
```
## 2. Circuit and Component Symbols
```
11. Ω: Ohm — unit of resistance.
12. F: Farad — unit of capacitance.
13. H: Henry — unit of inductance.
14. W: Watt — unit of power.
15. A: Ampere — unit of current.
16. V (unit): Volt — unit of voltage.
17. C (unit): Coulomb — unit of charge.
18. Hz: Hertz — unit of frequency.
19. kΩ: Kilo-ohm — 1000 ohms.
20. MΩ: Mega-ohm — 1,000,000 ohms.
```
## 3. Passive Component Symbols
```
21. R: Resistor — limits current and drops voltage.
22. C: Capacitor — stores electric charge in an electric field.
23. L: Inductor — stores energy in a magnetic field.
24. VR / POT: Variable resistor / potentiometer — adjustable resistance.
25. TRIM: Trimmer potentiometer — small adjustable resistor for calibration.
26. FB: Ferrite bead — suppresses high-frequency noise.
27. XTAL: Crystal — frequency reference used in clocks and oscillators.
28. OSC: Oscillator — generates periodic signals.
```
## 4. Diode and Semiconductor Symbols
```
29. D: Diode — allows current mainly in one direction.
30. LED: Light-emitting diode — diode that emits light.
31. Zener diode: Voltage regulation / reverse-voltage reference component.
32. Schottky diode: Fast diode with low forward voltage drop.
33. Q: Transistor — used as a switch or amplifier.
34. BJT: Bipolar junction transistor — current-controlled transistor.
35. MOSFET: Field-effect transistor used for efficient switching.
36. NPN: BJT type with current flow controlled by base current.
37. PNP: BJT type with opposite polarity behavior.
38. NMOS: N-channel MOSFET — common low-side switch.
39. PMOS: P-channel MOSFET — common high-side switch.
40. IC: Integrated circuit — many components inside one chip.
```
## 5. Power and Source Symbols
```
41. VCC: Positive supply voltage in many logic circuits.
42. VDD: Positive supply rail, especially in MOS circuits.
43. VSS: Ground or negative reference in many MOS circuits.
44. GND: Ground — circuit reference point.
45. VIN: Input supply voltage.
46. VOUT: Output voltage.
47. BAT: Battery — DC power source.
48. AC: Alternating current source.
49. DC: Direct current source.
50. PSU: Power supply unit — converts or provides power.
```
## 6. Measurement and Signal Symbols
```
51. Sin wave symbol: AC waveform.
52. Square wave symbol: Digital pulse or PWM signal.
53. Triangle wave symbol: Ramp or oscillator waveform.
54. CLK: Clock signal — timing reference for digital circuits.
55. RST / RESET: Reset signal — restarts a digital circuit.
56. IN / OUT: Input and output terminals.
57. TX: Transmit line — sending data.
58. RX: Receive line — receiving data.
59. SDA: I2C data line.
60. SCL: I2C clock line.
61. MOSI: SPI master-out slave-in data line.
62. MISO: SPI master-in slave-out data line.
63. SCK / CLK: SPI clock line.
64. CS / SS: Chip select or slave select line.
```
## 7. Logic and Digital Symbols
```
65. 0: Logic LOW — near ground voltage.
66. 1: Logic HIGH — near supply voltage.
67. AND: Output is true only if all inputs are true.
68. OR: Output is true if any input is true.
69. NOT: Inverter — flips logic state.
70. NAND: NOT-AND gate.
71. NOR: NOT-OR gate.
72. XOR: Exclusive OR gate.
73. XNOR: Exclusive NOR gate.
74. FF: Flip-flop — one-bit memory element.
75. MUX: Multiplexer — selects one of many inputs.
76. DEMUX: Demultiplexer — sends one input to one of many outputs.
77. ADC: Analog-to-digital converter.
78. DAC: Digital-to-analog converter.
```
## 8. Current Flow and Direction Symbols
```
79. →: Direction of current flow or signal movement.
80. + / -: Positive and negative polarity.
81. ~: Alternating signal or approximate value.
82. ≡: Electrical connection or equivalence in some diagrams.
83. ⏚: Earth ground or chassis ground in many diagrams.
84. ⊥: Reference or perpendicular notation in some contexts.
85. ↑ / ↓: Rising or falling signal state.
```
## 9. Common Circuit Notation
```
86. node: A connection point where circuit elements join.
87. branch: A separate current path in a circuit.
88. loop: A closed path through a circuit.
89. rail: Main power line such as VCC or GND.
90. bias: Setting a transistor or diode into a desired operating state.
91. load: The part of the circuit that consumes power.
92. source: The part that supplies power or signal.
93. sink: A path that receives current, often toward ground.
94. pull-up: Resistor that holds a signal high.
95. pull-down: Resistor that holds a signal low.
96. open circuit: Broken path with no current flow.
97. short circuit: Very low-resistance unintended path.
98. ground loop: Unwanted current path through multiple ground references.
```
## 10. Common Measurement Symbols
```
99. mA: Milliampere — one-thousandth of an ampere.
100. mV: Millivolt — one-thousandth of a volt.
101. µA: Microampere — one-millionth of an ampere.
102. µF: Microfarad — common capacitor unit.
103. nF: Nanofarad — smaller capacitor unit.
104. pF: Picofarad — very small capacitor unit.
105. kHz: Kilohertz — thousand cycles per second.
106. MHz: Megahertz — million cycles per second.
107. dB: Decibel — logarithmic ratio used in signals and gain.
```
## 11. Thermal Symbols
```
108. Tj: Junction temperature — internal semiconductor temperature.
109. Ta: Ambient temperature — surrounding air temperature.
110. Tc: Case temperature — temperature of component package.
111. Rθ: Thermal resistance — how hard it is for heat to move away.
112. ΔT: Temperature rise — increase above ambient.
```
## 12. Safety and Protection Symbols
```
113. Fuse: Sacrificial protection device that opens under excess current.
114. PTC: Resettable fuse or positive temperature coefficient device.
115. MOV: Metal oxide varistor — surge suppression component.
116. TVS: Transient voltage suppressor — protects against voltage spikes.
117. ESD: Electrostatic discharge protection marking or concept.
118. Isolation: Separation between circuits for safety or noise reduction.
```
## 13. Quick Meaning Summary
```
119. Resistor: controls current.
120. Capacitor: stores electric field energy.
121. Inductor: stores magnetic field energy.
122. Diode: one-way current path.
123. Transistor: controlled switch or amplifier.
124. Ground: reference point.
125. Voltage: electrical pressure.
126. Current: electron flow.
127. Power: rate of energy use.
128. Frequency: cycles per second.
```
