# Power Supply - Voltage Regulators

## What is a Voltage Regulator?

A voltage regulator is an electronic circuit or device that maintains a constant output voltage regardless of changes in input voltage or load current. It takes an unstable or varying input voltage and produces a stable, fixed output voltage essential for sensitive electronic circuits.

Voltage regulators are critical components in virtually all electronic devices. Microprocessors, memory chips, sensors, and analog circuits all require stable power to function correctly. Without regulation, voltage fluctuations would cause erratic behavior, data corruption, or permanent damage.

## Linear Voltage Regulators

### How Linear Regulators Work

Linear regulators use a pass transistor as a variable resistor.

```
LINEAR REGULATOR PRINCIPLE

     Vin (Unregulated)                                         Vout (Regulated)
   ───────┬───────────────────[ Pass Transistor ]───────────────────┬───────►
          │                          ▲                              │
          │                          │ (Control Signal)             │
          │                  ┌───────┴───────┐                      │
          │                  │     Error     │                      │
          │                  │   Amplifier   │                      │
          │                  └────▲─────▲────┘                      │
          │                       │     │                           │
          │      ┌────────────────┘     └──────────────┐            │
          │      │ (Ref Voltage)                       │ (Feedback) │
          │  ┌───┴───────────────┐             ┌───────┴───────┐    │
          │  │ Voltage Reference │             │   Feedback    │    │
          │  │  (Bandgap 1.25V)  │             │    Divider    ├────┘
          │  └───────────┬───────┘             │   (R1, R2)    │
          │              │                     └───────┬───────┘
          │              │                             │
   ───────┴──────────────┴─────────────────────────────┴────────────► GND

    OPERATION:
    ├── Pass transistor acts as variable resistor
    ├── If V_out drops → error amp turns transistor ON more
    ├── If V_out rises → error amp turns transistor OFF more
    ├── Excess voltage (V_in - V_out) is DROPPED across transistor
    └── Dropped voltage becomes HEAT: P = (V_in - V_out) × I_out


    SIMPLE ANALOGY: Water faucet
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   Water pressure = Voltage                                  │
    │   Water flow = Current                                      │
    │   Faucet valve = Pass transistor                            │
    │                                                             │
    │   You adjust valve to get constant flow regardless of       │
    │   inlet pressure. The valve (transistor) dissipates         │
    │   the excess pressure as heat.                              │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘
```

```
    V_out = V_ref × (1 + R2 / R1) + I_adj × R2

    V_ref = 1.25V (internal reference)
    I_adj ≈ 50-100µA (usually negligible, 1% error)

    V_out = 1.25V × (1 + R2 / R1)

    ├── C1 = 0.1-1µF (input capacitor, required)
    ├── C2 = 1-10µF tantalum (output capacitor, improves stability)
    ├── D1, D2 protection diodes (optional but recommended)
    └── Heatsink required for >500mA or high V_in - V_out
```

### Linear Regulator Limitations

```
POWER DISSIPATION (HEAT)

    P_diss = (V_in - V_out) × I_out

    EXAMPLES:

    1. 7805, V_in = 12V, I_out = 0.5A:
       P_diss = (12 - 5) × 0.5 = 7 × 0.5 = 3.5W

    2. 7805, V_in = 9V, I_out = 1A:
       P_diss = (9 - 5) × 1 = 4 × 1 = 4W

    3. LM317, V_in = 24V, V_out = 5V, I_out = 0.5A:
       P_diss = (24 - 5) × 0.5 = 19 × 0.5 = 9.5W (needs large heatsink!)


    HEATSINK REQUIREMENTS:

    P_diss (W)   Heatsink Required (for TO-220)
    ──────────────────────────────────────────────────────────────
    <0.5W        None (free air)
    0.5-1W       Small clip-on heatsink
    1-2W         Medium heatsink (25×25×15mm)
    2-5W         Large heatsink (50×50×25mm) + fan recommended
    >5W          Consider switching regulator


    EFFICIENCY:

    η = P_out / P_in = (V_out × I_out) / (V_in × I_out) = V_out / V_in

    Examples:
    ├── 12V to 5V: η = 5/12 = 41.7% (very inefficient!)
    ├── 9V to 5V:  η = 5/9 = 55.6%
    ├── 7.5V to 5V: η = 5/7.5 = 66.7%

    Linear regulators are inefficient when V_in is much higher than V_out.
    Most of the power is wasted as heat!


    DROPOUT VOLTAGE:

    Minimum voltage difference between input and output for regulation.

    78xx series:    2.0V (older), 1.5V (L78xxCV newer)
    LM317:          2.5V typical, 3V worst case
    Low-dropout (LDO): 0.1-1.0V (e.g., LM2940, 29302, 1117 series)

    If V_in - V_out < dropout voltage, regulator "drops out"
    (output falls below regulation, ripple appears)
```

## Low Dropout Regulators (LDO)

### What Makes LDO Different

LDOs use a PNP or P-channel pass transistor for lower dropout.

```

    Standard NPN regulator:         LDO (PNP or PMOS):
    
    V_in ──► NPN pass ──► V_out     V_in ──► PNP/PMOS pass ──► V_out
              transistor                          transistor
    
    Base needs 1.2-2.0V above      Emitter/Source can be close to
    output to keep transistor      output (V_CE(sat) or R_DS(on))
    in active region
    
    Dropout ≈ 2V                    Dropout ≈ 0.1-1.0V


    LDO ADVANTAGES:
    ├── Lower dropout (e.g., 0.5V instead of 2V)
    ├── Higher efficiency (when V_in close to V_out)
    ├── Longer battery life (uses more battery capacity)
    └── Smaller heatsink (less power dissipation)

    LDO DISADVANTAGES:
```

## Switching Regulators

### Why Use Switching Regulators

Switching regulators are much more efficient than linear regulators.

```
SWITCHING REGULATOR PRINCIPLE

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   V_in ──► Switch ──► Inductor ──► Capacitor ──► V_out    │
    │              (MOSFET)       (L)           (C)              │
    │               │                                            │
    │               │     ┌─────────────────────────────┐        │
    │               └────►│    PWM Controller           │        │
    │                     │    (adjusts duty cycle)     │        │
    │                     │        │                   │        │
    │                     │        │                   │        │
    │                     │   Feedback (V_out)         │        │
    │                     └─────────────────────────────┘        │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘

    HOW IT WORKS:
    ├── Switch turns ON and OFF at high frequency (50kHz-2MHz)
    ├── When ON: Inductor stores energy, capacitor charges
    ├── When OFF: Inductor releases energy, capacitor supplies load
    ├── Duty cycle (ON time) determines output voltage
    └── Energy is transferred via magnetic field (inductor)


    EFFICIENCY:

    Linear regulator:   η = V_out / V_in  (e.g., 5V/12V = 42%)
    Switching regulator: η = 80-95% (independent of voltage)

    Example (12V to 5V, 1A output):
    ├── Linear: P_diss = (12-5) × 1 = 7W (needs big heatsink!)
    └── Switching: P_diss = 5W ÷ 0.90 - 5W = 5.56W - 5W = 0.56W (tiny heatsink)

    Switching regulators are MUCH more efficient for large voltage drops!
```

### Switching Regulator Topologies

## Linear vs Switching Comparison

```
COMPARISON TABLE

    Feature                 Linear Regulator       Switching Regulator
    ──────────────────────────────────────────────────────────────
    Efficiency              Low (20-60%)          High (80-95%)
    Heat dissipation        High                   Low
    Size/Weight             Large heatsink         Small
    Output noise            Very low (<1mV)        Higher (10-100mV ripple)
    Transient response      Very fast              Good (but slower)
    EMI / RFI               None                   Yes (requires filtering)
    Complexity              Simple                 Complex
    Cost (low power)        Low                    Higher
    Cost (high power)       Very high (heatsink)   Low
    Input range             Limited (min V_in)     Wide
    Step-up capability      No                     Yes (boost)
    Inverting capability    No                     Yes (buck-boost)
    Minimum load required   Sometimes (LM317)      Usually not
    Stability               Always stable          Needs careful design
    Output capacitor        Not critical           ESR matters!
    Quiescent current       1-10mA (78xx)          100µA-10mA (varies)


    SELECTION GUIDE:

    Use Linear Regulator when:
    ├── Low output noise is critical (audio, RF, precision analog)
    ├── V_in is close to V_out (efficiency acceptable)
    ├── Output current is low (<100mA)
    ├── Simple circuit needed (hobby, prototyping)
    ├── EMI cannot be tolerated (medical, avionics)
    └── Cost for low power is important

    Use Switching Regulator when:
    ├── Efficiency matters (battery-powered devices)
    ├── Large voltage drop (e.g., 24V to 3.3V)
    ├── High output current (>500mA)
    ├── Small size required (no large heatsink)
    ├── Input voltage varies widely (battery, USB, etc.)
    ├── Step-up or inverting needed
    └── Cost for high power is important
```

## Thermal Management

### Heatsink Calculation

```
HEATSINK SIZING

    THERMAL RESISTANCE MODEL:

    T_j (junction) ──► R_θjc ──► T_case ──► R_θcs ──► T_sink ──► R_θsa ──► T_amb

    WHERE:
    R_θjc = Junction-to-case (internal, from datasheet)
    R_θcs = Case-to-sink (thermal paste: 0.1-0.5°C/W)
    R_θsa = Sink-to-ambient (heatsink specification)
    T_j_max = Maximum junction temperature (125-150°C for most)
    T_amb = Ambient temperature (25°C typical, 50°C worst case)


    CALCULATION EXAMPLE (LM317, 24V to 5V, 0.5A):

    P_diss = (24V - 5V) × 0.5A = 9.5W

    From datasheet: R_θjc = 3°C/W (TO-220)
    Estimate: R_θcs = 0.5°C/W (with thermal paste)

    Max allowed temperature rise = T_j_max - T_amb = 125 - 25 = 100°C

    Required R_θsa = (100°C / P_diss) - R_θjc - R_θcs
                    = (100 / 9.5) - 3 - 0.5
                    = 10.5 - 3 - 0.5 = 7°C/W

    Need heatsink with R_θsa ≤ 7°C/W (medium size, approx 40×40×25mm)

    Without heatsink (R_θja = 65°C/W):
    Temperature rise = 9.5W × 65°C/W = 617°C → regulator burns!
```

## Summary

1. **Voltage regulator** maintains constant output voltage despite input/load variations

2. **Linear regulator** drops excess voltage as heat: P = (V_in - V_out) × I_out

3. **Linear efficiency** = V_out / V_in (12V to 5V = 42% efficiency!)

4. **78xx series** fixed linear regulators: 7805 (5V), 7812 (12V), etc.

5. **LM317** adjustable linear regulator: V_out = 1.25V × (1 + R2/R1)

6. **Dropout voltage** = minimum V_in - V_out for regulation (2V for 78xx, 0.1-1V for LDO)

7. **LDO (Low Dropout)** regulators work with V_in close to V_out (battery applications)

8. **Heatsink required** when P_diss > 0.5W for TO-220, >0.1W for TO-92

9. **Switching regulator** uses inductor to transfer energy, much more efficient (80-95%)

10. **Buck converter** steps down voltage (most common, V_out < V_in)

11. **Boost converter** steps up voltage (V_out > V_in, e.g., 3.7V→5V USB)

12. **Buck-boost** can step up or down (V_out can be higher or lower than V_in)

13. **Switching efficiency** independent of voltage ratio (unlike linear)

14. **Switching ripple** higher (20-100mV) – may need post-filter for sensitive circuits

15. **LM2596** popular switching module: 3A, adjustable, $2-3

16. **Thermal runaway** risk with linear regulators at high power – use proper heatsink

17. **Input/output capacitors** required for stability (ESR matters for LDOs)

18. **Quiescent current** (ground pin current) wastes power – important for battery devices

19. **Linear regulators** for low noise (audio, RF, precision), switching for efficiency

20. **Module solutions** (LM2596, XL4015, MP1584) are easy to use for prototyping
