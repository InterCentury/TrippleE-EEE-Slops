# 08.01 - Analog vs. Digital Electronics: Signal Metrology, Processing Architectures, and Circuit Quantization

## 1. Fundamental Metrology of Continuous and Discrete States

In electronic engineering, information is encoded, transmitted, and processed using electrical variables—specifically voltage ($V$) or current ($I$). The fundamental classification of an electronic system depends entirely on whether these variables operate over a continuous spectrum or within a discrete, quantized state space.

### 1.1 Analog Signals

An analog signal is a continuous time-varying quantity where every infinitesimal change in the signal value represents unique, distinct information. The signal can be mathematically modeled as a continuous function of time:

$$f(t) = X_{\text{max}} \cdot \sin(\omega t + \phi)$$

Where:

* $f(t)$ = **Instantaneous signal amplitude** (voltage or current) at any specific moment, measured in Volts ($\text{V}$) or Amperes ($\text{A}$).
* $X_{\text{max}}$ = **Peak amplitude** of the continuous waveform, measured in Volts ($\text{V}$) or Amperes ($\text{A}$).
* $\omega$ = **Angular frequency** of the waveform, measured in radians per second ($\text{rad/s}$), calculated via $\omega = 2\pi f$.
* $t$ = **Time variable**, measured in seconds ($\text{s}$).
* $\phi$ = **Phase angle offset**, measured in radians ($\text{rad}$).

Because the physical real-world domain is inherently continuous (e.g., sound pressure, temperature, light intensity), sensors naturally produce analog waveforms.

```text
> ANALOG CONTINUOUS TIME WAVEFORM PROFILE

  Voltage (V)
      ▲
  +V  │      █▀█
      │     █   █
   0  ┼────█─────█─────█─────► Time (t)
      │   █       █   █
  -V  │  █         █▄█

```

### 1.2 Digital Signals

A digital signal is a discrete, quantized representation of information. Instead of possessing an infinite number of states, digital variables are restricted to a finite set of specific values, most commonly the binary system composed of Logic Low ($0$) and Logic High ($1$).

```text
> DIGITAL DISCRETE TIME QUANTIZED WAVEFORM

  Voltage (V)
      ▲
  5V  │  ┌───────┐       ┌───────┐
      │  │       │       │       │
   0  ┼──┴───────┴───────┴───────┴───► Time (t)
         [ 1 ]   [ 0 ]   [ 1 ]   [ 0 ]

```

The transmission of a binary signal is characterized by the bit rate ($R$):

$$R = \frac{n}{T}$$

Where:

* $R$ = **Data bit rate**, measured in bits per second ($\text{bps}$).
* $n$ = **Number of bits** transmitted.
* $T$ = **Total time duration** of the transmission slot, measured in seconds ($\text{s}$).

## 2. Signal Distortions, Noise Vulnerability, and Degradation

The core engineering trade-off between analog and digital paradigms lies in how noise interacts with the transmission medium.

```text
> NOISE INTERFERENCE CORRUPTION TRAJECTORY

  [ Original Clean Signal ] ──► [ Thermal / EMI Noise Channel ] ──► [ Corrupted Output Waveform ]

```

### 2.1 Analog Noise Degradation

In the analog domain, thermal noise, crosstalk, and electromagnetic interference (EMI) mix directly into the signal amplitude. Because every infinitesimal voltage variation carries meaning, an analog circuit cannot distinguish between the original signal voltage and the noise voltage:

$$V_{\text{received}}(t) = V_{\text{signal}}(t) + V_{\text{noise}}(t)$$

Where:

* $V_{\text{received}}(t)$ = **Total composite voltage** arriving at the receiver node, measured in Volts ($\text{V}$).
* $V_{\text{signal}}(t)$ = **Original uncorrupted data signal**, measured in Volts ($\text{V}$).
* $V_{\text{noise}}(t)$ = **Stochastic noise voltage** introduced by physical paths, measured in Volts ($\text{V}$).

Once noise is added to an analog signal, it cannot be separated during amplification; amplifying the signal amplifies the noise along with it.

### 2.2 Digital Noise Immunity Thresholds

Digital circuits maintain superior noise immunity because they rely on **Noise Margins** ($NM$). Input circuits decode logic states based on wide voltage windows rather than exact values.

```text
> DIGITAL LOGIC VOLTAGE THRESHOLD ARCHITECTURE

  Voltage (V)
      ▲
  5.0V│ ┌───────────────────────────────────────┐
      │ │ LOGIC HIGH LEVEL (Binary 1)           │ Minimum Acceptable Input: V_IH
  3.5V│ ├───────────────────────────────────────┤
      │ │ INDETERMINATE FORBIDDEN ZONE          │ (Causes operational stability errors)
  1.5V│ ├───────────────────────────────────────┤
      │ │ LOGIC LOW LEVEL (Binary 0)            │ Maximum Acceptable Input: V_IL
  0.0V│ └───────────────────────────────────────┘

```

The high-level noise margin ($NM_H$) and low-level noise margin ($NM_L$) are calculated as:

$$NM_H = V_{OH} - V_{IH}$$

$$NM_L = V_{IL} - V_{OL}$$

Where:

* $V_{OH}$ = **Minimum output voltage** guaranteed by a logic gate driving a High state, measured in Volts ($\text{V}$).
* $V_{IH}$ = **Minimum input voltage** required by a receiving gate to reliably recognize a High state, measured in Volts ($\text{V}$).
* $V_{IL}$ = **Maximum input voltage** allowed by a receiving gate to reliably recognize a Low state, measured in Volts ($\text{V}$).
* $V_{OL}$ = **Maximum output voltage** produced by a logic gate driving a Low state, measured in Volts ($\text{V}$).

If a noise spike ($V_{\text{noise}}$) riding on a digital line does not push the signal across the noise margin threshold into the indeterminate forbidden zone, the receiving logic gate correctly resolves the original $0$ or $1$ state. This allows digital data to be copied and transmitted over long distances with zero cumulative degradation.

## 3. Data Domain Conversion: Sampling and Quantization

To link continuous real-world signals with digital processors, data must pass through **Analog-to-Digital Converters (ADC)** and **Digital-to-Analog Converters (DAC)**.

```text
> ANALOG TO DIGITAL MIXED-SIGNAL PIPELINE

  [ Continuous Analog Input ] ──► [ Sample & Hold Circuit ] ──► [ Quantization Matrix ] ──► [ Binary Bitstream Output ]

```

### 3.1 The Nyquist-Shannon Sampling Theorem

To prevent data loss when converting an analog signal into discrete time steps, the sampling frequency ($f_s$) must be strictly greater than twice the highest frequency component ($f_{\text{max}}$) contained within the analog source:

$$f_s > 2 \cdot f_{\text{max}}$$

Where:

* $f_s$ = **Sampling frequency**, indicating the number of discrete snapshots taken per second, measured in Hertz ($\text{Hz}$).
* $f_{\text{max}}$ = **Nyquist frequency frequency bound**, matching the absolute highest spectral component of the target signal, measured in Hertz ($\text{Hz}$).

If $f_s \le 2f_{\text{max}}$, a destructive distortion called **aliasing** occurs, folding high-frequency artifacts back into the lower frequency spectrum and permanently corrupting the data profile.

### 3.2 Quantization Resolution and Error

Quantization involves mapping a continuous voltage amplitude into a discrete binary code. The number of available quantization levels ($L$) is dictated by the bit resolution ($N$) of the converter:

$$L = 2^N$$

The voltage step size, or **Resolution Width** ($\Delta V$), represents the smallest voltage change the converter can detect:

$$\Delta V = \frac{V_{\text{FSR}}}{2^N}$$

Where:

* $\Delta V$ = **Quantization resolution step size**, measured in Volts ($\text{V}$).
* $V_{\text{FSR}}$ = **Full-Scale Voltage Range** of the converter, measured in Volts ($\text{V}$).
* $N$ = **Bit depth resolution** of the digital register (e.g., 8-bit, 12-bit, 16-bit).

Because a continuous value must be rounded to the nearest discrete step, an inherent rounding deviation called **Quantization Noise** or **Quantization Error** ($e_q$) is introduced, bounded by:

$$|e_q| \le \frac{\Delta V}{2}$$

## 6. Summary Summary Checklist

1. **Analog Continuity:** Analog systems use continuous electrical variables to represent data, where every minor amplitude shift corresponds to unique information.
2. **Digital Discretization:** Digital electronics restrict signal values to discrete, quantized states, typically using binary high ($1$) and low ($0$) logic configurations.
3. **Irreversible Analog Noise:** External noise voltage ($V_{\text{noise}}$) adds directly to analog signals and cannot be isolated out during amplification stages.
4. **Noise Margin Protection:** Digital circuits maintain noise immunity by utilizing predefined voltage input thresholds ($NM_H = V_{OH} - V_{IH}$) to reject small voltage fluctuations.
5. **The Nyquist Sampling Rule:** To prevent data loss during analog-to-digital conversion, the sampling clock must exceed twice the highest target frequency ($f_s > 2f_{\text{max}}$).
6. **Aliasing Distortions:** Sampling an analog signal below its Nyquist limit introduces aliasing, which folds phantom lower-frequency errors into the converted data.
7. **Quantization Scaling:** An ADC's total available discrete levels scale exponentially with its register bit depth, calculated via the binary relation $L = 2^N$.
8. **Quantization Rounding Error:** Converting continuous inputs into discrete steps introduces a rounding error ($e_q$) that is bounded by half the step size width ($\frac{\Delta V}{2}$).
9. **Automated Digital Synthesis:** Digital systems scale efficiently because circuits can be described using Hardware Description Languages (HDL) and compiled automatically.
10. **Metastable States:** Allowing digital signal voltages to hover inside the forbidden input window between $V_{IL}$ and $V_{IH}$ causes logic gate metastability and system processing failures.
